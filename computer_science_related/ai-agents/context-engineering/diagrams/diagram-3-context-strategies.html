Failure Analysis

Why Summarization Failed

Engineering teams often assume LLM summarization is the silver bullet for context compaction. In practice, LLM summarization is non-deterministic, hallucinates during recursive summaries, and frequently drops critical structured identifiers (like span IDs, timestamps, or exact SQL queries) required for downstream agent tool calls.

Production Solution

Smart Head/Tail + External Memory Store

The winning pattern used by Arize Alex and Claude Code:
1. Never reset the system prompt.
2. Preserve the Head (initial user goal) and Tail (immediate conversational turn).
3. Truncate the middle (verbose tool outputs) and persist full payloads into a database indexed by ID, giving the agent a tool to recall them on demand.

# SMART TRUNCATION + MEMORY STORE BLUEPRINT def prepare_context(system_prompt, messages, max_tokens=8000): """Preserves Head, Tail, and offloads verbose tool middles to DB.""" head_context = messages[:2] # Initial goal & setup tail_context = messages[-4:] # Latest recency turns middle_messages = messages[2:-4] # Verbose tool calls # Offload middle messages to DB for msg in middle_messages: if len(msg["content"]) > 500: db_id = save_to_memory_store(msg) msg["content"] = f"[TRUNCATED - ID: {db_id}. Use tool 'fetch_context({db_id})' to expand]" return [system_prompt] + head_context + middle_messages + tail_context
