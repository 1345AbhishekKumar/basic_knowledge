Detailed Architectural Explanations

Evaluation Pattern

The Turn-11 Evaluation Pattern

Standard unit tests only evaluate Turn 1. However, in production applications, users traverse multiple pages, causing sessions to extend beyond 20 turns. The Turn-11 Eval loads 10 realistic historical turns (filled with tool calls, middle truncations, and conversation shifts) and tests whether Turn 11 accurately recalls critical facts from Turn 2.

Cost & Latency

Cache-Aware Context Layout

Modern frontier providers (Anthropic Claude, Google Gemini) offer prompt caching discounts (up to 80-90% cheaper for cached prefixes). If an agent modifies its system prompt or inserts dynamic timestamps at the beginning of the context, it invalidates the entire cache. Keeping a deterministic static prefix ensures high cache hit rates across long multi-turn sessions.
