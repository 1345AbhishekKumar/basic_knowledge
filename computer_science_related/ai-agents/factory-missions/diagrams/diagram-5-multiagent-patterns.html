Detailed Architectural Explanations

Pattern 02 · Essential

Creator-Verifier & Sunk-Cost Bias

When an agent writes code, it develops an inherent bias toward believing its implementation is correct. If the same agent is asked to test its own code, it writes tests that merely confirm its previous assumptions. Creator-Verifier separates implementation and testing into two distinct agents with fresh context windows.

Pattern 04 & 05

Negotiation & Broadcast for Multi-Day Runs

For missions lasting days or weeks (e.g. Factory's 16-day Slack clone build), Broadcast ensures all agents share a single source of truth without drift, while Negotiation resolves shared resource conflicts at milestone boundaries through structured handoff contracts.
