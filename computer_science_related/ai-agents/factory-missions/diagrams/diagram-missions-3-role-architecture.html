Factory Missions: The 3-Role Multi-Agent Ecosystem

How Factory (makers of Goose) orchestrates multi-day autonomous software development using an ecosystem of Orchestrators, Clean-Context Workers, and Adversarial Validators.

FIGURE 2.0 — FACTORY MISSIONS 3-ROLE ECOSYSTEM & DUAL VALIDATOR PIPELINE

Detailed Architectural Explanations

Role 01 & 02

Orchestrator & Clean-Context Workers

The Orchestrator scopes the goal with the human user, writing a Pre-Code Validation Contract with hundreds of behavioral assertions. Workers execute one feature at a time with clean context, committing changes to Git so subsequent workers inherit an immaculate codebase without token baggage.

Role 03 · Dual Validators

Scrutiny vs. User Testing (Computer Use)

Factory uses two adversarial validators: Scrutiny Validator runs static checks and parallel code reviews; User Testing Validator boots up the live app and uses Computer Use to click buttons and fill forms. Because live execution takes real time, most mission wall-clock time is spent waiting on functional QA rather than token generation.
