Detailed Architectural Explanations

The Confirmation Trap

Why Tests Written After Code Fail

When an agent writes code and immediately writes unit tests for it, the tests inevitably reflect the agent's internal assumptions. If the code omits an edge case, the test suite omits the edge case as well. By establishing the Validation Contract before coding, the definition of success remains completely independent of the implementation.

Self-Healing

The Structured Handoff Protocol

Instead of relying on LLM memory across days, each worker writes a rigorous Structured Handoff document: exact files edited, terminal commands executed with exit codes, open bugs discovered, and SOP compliance. The orchestrator inspects this handoff at milestone boundaries, automatically scheduling corrective sub-tasks when anomalies appear.
