Kimi K3: 2.8T Parameter Architecture & Sparse MoE

How Moonshot AI's Kimi K3 achieves 1M context reasoning and long-horizon agentic coding using an 896-expert sparse MoE (16 active / ~50B awake) and linear Delta Attention.

Detailed Architectural Explanations

1. Core Component Definitions (From Diagram Elements)

Every architectural layer, sparsity metric, and attention block shown in Figure 1.0 is formally defined below:

896 TOTAL EXPERTS (2.8T PARAMETERS)

The overarching parameter pool of Kimi K3. Contains 896 independently specialized feed-forward networks holding 2.8 Trillion cumulative weights, providing immense pre-trained knowledge across reasoning, multilingual data, and codebase semantics.

DYNAMIC TOP-16 ROUTER

The gating network in Panel 1. Evaluates token representations and dynamically calculates softmax affinity weights to awaken only the top 16 most relevant experts for that specific token, leaving the remaining 880 experts dormant.

~50B ACTIVE PARAMETERS

The effective computational weight loaded during inference. Because only 16 experts execute per token, the model delivers the speed and memory efficiency of a ~50 Billion parameter dense model while wielding the reasoning capacity of a 2.8T model.

1.78% SPARSITY RATIO

The mathematical activation ratio: $16 / 896 \approx 1.78\%$. Exactly 98.22% of parameters remain completely uncomputed per forward pass, dramatically cutting energy consumption and GPU thermal load.

O(N²) QUADRATIC ATTENTION WALL

Illustrated at the top of Panel 2: Standard softmax attention calculates pairwise dot products between all $N$ tokens. Doubling tokens quadruples compute ($2\times \text{tokens} \rightarrow 4\times \text{work}$), creating an impassable barrier for 1M context agent loops.

KIMI DELTA ATTENTION (KDA) (O(N))

Illustrated at the center of Panel 2: Formulates self-attention as a linear recursive running mean $S_t = \lambda S_{t-1} + v_t q_t^T$. Eliminates the $N \times N$ matrix and processes 1 Million token contexts with constant decode latency.

ATTENTION RESIDUALS & LOOP REUSE

Tailored specifically for agentic harnesses. In an iterative loop, the system prompt, tool definitions, and repository tree are repeated across every turn. Kimi K3 reuses cached attention activations from prior turns, unlocking up to 10× cheaper per-turn pricing.

1M REASONING HORIZON (PANEL 3)

The combined architectural payoff: Kimi K3 ingests full git repositories, extensive API documentations, and lengthy multi-turn execution traces into its live context window without truncation or memory overflow.

3. Concrete Implementation Blueprint: Kimi K3 Sparse MoE Router & KDA Step

The Python implementation below models both the 896-expert top-16 sparse router and the linear Delta Attention recurrent state update: 

import torch
import torch.nn as nn
import torch.nn.functional as F

class KimiK3TopKRouter(nn.Module):
    """896 total experts with dynamic top-16 sparse routing (1.78% active)."""
    def __init__(self, d_model: int = 128, num_experts: int = 896, top_k: int = 16):
        super().__init__()
        self.num_experts = num_experts
        self.top_k = top_k
        self.gate = nn.Linear(d_model, num_experts, bias=False)

    def forward(self, x: torch.Tensor):
        # x shape: [batch_size, d_model]
        logits = self.gate(x)  # [batch_size, 896]
        # Select top-16 experts per token
        topk_weights, topk_indices = torch.topk(logits, self.top_k, dim=-1)
        # Softmax normalize over the active 16 experts only
        topk_weights = F.softmax(topk_weights, dim=-1)
        return topk_weights, topk_indices

class KimiDeltaAttentionLayer(nn.Module):
    """Linear O(N) attention with recursive running average state update."""
    def __init__(self, d_model: int = 128):
        super().__init__()
        self.d_model = d_model
        self.decay_lambda = 0.95

    def step(self, prev_state: torch.Tensor, q_t: torch.Tensor, k_t: torch.Tensor, v_t: torch.Tensor):
        """Single-step recursive delta attention: O(1) time per token."""
        # prev_state shape: [d_model, d_model]
        # Predict current value vector based on previous state
        predicted_v = torch.matmul(prev_state, k_t)
        delta_v = v_t - predicted_v
        
        # Recursive state update without N^2 pairwise matrix
        new_state = self.decay_lambda * prev_state + torch.outer(delta_v, k_t)
        output_t = torch.matmul(new_state, q_t)
        return output_t, new_state

if __name__ == "__main__":
    d_model = 64
    router = KimiK3TopKRouter(d_model=d_model, num_experts=896, top_k=16)
    kda = KimiDeltaAttentionLayer(d_model=d_model)

    sample_token = torch.randn(1, d_model)
    weights, indices = router(sample_token)
    print(f"[*] Top-16 Expert Indices selected: {indices[0].tolist()[:8]}... (16 of 896)")
    print(f"[*] Total Awake Parameters: ~50B (1.78% of 2.8T Pool)")

    # Execute linear recurrent attention step
    state = torch.zeros(d_model, d_model)
    q = torch.randn(d_model)
    k = torch.randn(d_model)
    v = torch.randn(d_model)
    out_token, next_state = kda.step(state, q, k, v)
    print(f"[✓] Delta Attention Step computed in O(1) time. Next State Shape: {next_state.shape}")
