Kimi K3: 2.8T Parameter Architecture & Sparse MoE

How Moonshot AI's Kimi K3 achieves 1M context reasoning and long-horizon agentic coding using an 896-expert sparse MoE (16 active / ~50B awake) and linear Delta Attention.

Detailed Architectural Explanations

Innovation 01

2.8 Trillion Parameters with 1.78% Sparsity

Traditional dense models activate every single parameter for every token, hitting severe compute and latency walls. Kimi K3 features 896 total experts (~2.8T parameters), but the dynamic top-16 router only awakens 16 experts per token (~50B active parameters). This gives the model world-class knowledge capacity while executing at the speed of a medium-sized model.

Innovation 02 · Core Breakthrough

Kimi Delta Attention (KDA)

Standard softmax attention computes all pairwise token interactions, creating an $O(N^2)$ quadratic cost. KDA replaces this with a recursive running average (exponentially weighted moving average). Instead of re-evaluating the entire history at each step, it updates a continuous attention state in $O(N)$ linear time, making 1M token contexts viable for multi-turn agent harnesses.

# CONCEPTUAL DELTA ATTENTION UPDATE VS QUADRATIC ATTENTION # 1. Standard Transformer Attention: O(N^2) # Attention(Q, K, V) = softmax(Q * K.T / sqrt(d)) * V -> All pairs recomputed! # 2. Kimi Delta Attention (KDA): O(N) Linear Recursive State def delta_attention_step(prev_state, query_t, key_t, value_t, decay_lambda=0.95): """Updates attention state recursively like an exponential running mean.""" # Compute error/delta against current key-state projection predicted_v = prev_state @ key_t delta_v = value_t - predicted_v # Linear recursive update without pairwise N^2 matrix new_state = decay_lambda * prev_state + (delta_v[:, None] @ key_t[None, :]) output_t = new_state @ query_t return output_t, new_state
