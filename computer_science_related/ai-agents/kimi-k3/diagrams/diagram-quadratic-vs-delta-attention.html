Quadratic Attention vs. Kimi Delta Attention

Why standard Transformers scale quadratically as $O(N^2)$ and how Kimi Delta Attention (KDA) replaces all-to-all pairwise calculation with an $O(N)$ linear running mean.

FIGURE 2.0 — QUADRATIC ATTENTION (O(N²)) VS. KIMI DELTA ATTENTION (O(N))

Detailed Architectural Explanations

1. Core Component Definitions (From Diagram Elements)

Every mathematical structure, matrix operation, and scaling law illustrated in Figure 2.0 is formally defined below:

PAIRWISE ALL-TO-ALL ATTENTION MATRIX

The foundational calculation of standard transformers (Left Panel). Every token queries all prior tokens by computing an explicit $N \times N$ Gram matrix of dot products: $\text{Attention}(Q, K, V) = \text{softmax}(QK^T / \sqrt{d})V$.

QUADRATIC MATRIX SCALING (N²)

The visual dot-grid progression in Panel 1: 10 tokens produce 100 dot products; 100 tokens produce 10,000 dot products; 1 Million tokens produce $10^{12}$ (1 Trillion) pairwise dot products, requiring petabytes of intermediate memory bandwidth.

THE QUADRATIC COST WALL

The computational penalty where doubling context length quadruples required FLOPs ($2\times \text{tokens} \rightarrow 4\times \text{work}$). During iterative agent loops, recalculating this quadratic matrix on every turn quickly exhausts hardware budgets.

KV CACHE MEMORY BLOWUP

In standard attention, Key and Value tensors for every historical token must be kept uncompressed in GPU High Bandwidth Memory (HBM). At 1M tokens, this requires hundreds of gigabytes per concurrent user stream.

RECURSIVE RUNNING STATE UPDATE

The core mechanism of Kimi Delta Attention (Right Panel). Rather than storing an unbounded list of historical keys and values, KDA maintains a fixed-size hidden state matrix $S_t$ updated recursively via an exponentially weighted moving average.

LINEAR FLOW CHAIN (STATE t-1 → DELTA → STATE t)

The step-by-step update pipeline: $S_t = \lambda S_{t-1} + (v_t - S_{t-1} k_t) k_t^T$. New incoming tokens only compute an error delta against the existing state, requiring constant $O(1)$ compute per token.

O(N) LINEAR SCALING

Under KDA, doubling the sequence length exactly doubles the compute ($2\times \text{tokens} \rightarrow 2\times \text{work}$). Processing 1 Million tokens requires only 1 Million linear recurrent updates, eliminating the quadratic cost wall.

ATTENTION RESIDUALS & LOOP REUSE

Because state updates are strictly linear and continuous, state matrices from turn $k$ are cached in RAM. On turn $k+1$, the harness initializes from this cached state, reducing agent loop execution costs by up to 10×.

2. Step-by-Step Operational Comparison

Tracing the execution divergence between the Left and Right panels during long-context decoding:

  1. 1

    Left: Pairwise Matrix Evaluation (Quadratic Path)

    At step $N$, standard attention computes a new query vector $q_N$ and performs a dot product against all previous keys $k_1, k_2, \dots, k_{N-1}$. The resulting vector must be softmax-normalized across all $N$ elements, incurring an $O(N^2)$ cumulative workload.

  2. 2

    Left: GPU KV Cache Saturation

    The Key and Value tensors cannot be discarded; they append to GPU VRAM indefinitely. When the context window reaches 1M tokens, the memory footprint exceeds the capacity of standard inference clusters, causing out-of-memory crashes or extreme quantization degradation.

  3. 3

    Right: Recursive State Read (Linear Path)

    At step $t$, Kimi Delta Attention retrieves the constant-sized hidden state $S_{t-1}$. No historical keys or values need to be fetched from memory, preserving memory bandwidth.

  4. 4

    Right: Delta Update & Constant Time Step

    The new token generates its delta vector: $\Delta v_t = v_t - S_{t-1} k_t$. The state is updated in $O(1)$ time: $S_t = \lambda S_{t-1} + \Delta v_t k_t^T$. The token output $y_t = S_t q_t$ is emitted immediately.

  5. 5

    Right: Turn-to-Turn State Caching in Agent Loops

    Upon finishing a tool turn, the agent freezes state matrix $S_{\text{final}}$. In the next turn, rather than re-ingesting the entire conversation history, the model resumes directly from $S_{\text{final}}$, delivering a 10× reduction in operational cost.

3. Concrete Implementation Blueprint: Benchmark Code

The Python code below demonstrates the memory and compute difference between quadratic attention and recursive delta attention: 

import time
import torch
import torch.nn.functional as F

def benchmark_attention_scaling():
    device = "cpu"  # Works across standard environments
    dim = 64
    seq_lengths = [256, 1024, 4096]

    print(f"{'Seq Len':<10} | {'Quadratic O(N^2) Time':<22} | {'Delta O(N) Time':<20} | {'Ratio':<8}")
    print("-" * 68)

    for seq_len in seq_lengths:
        Q = torch.randn(seq_len, dim)
        K = torch.randn(seq_len, dim)
        V = torch.randn(seq_len, dim)

        # 1. Quadratic Softmax Attention (Computes N x N matrix)
        t0 = time.perf_counter()
        scores = torch.matmul(Q, K.T) / (dim ** 0.5)  # [N, N]
        weights = F.softmax(scores, dim=-1)
        out_quad = torch.matmul(weights, V)
        t_quad = time.perf_counter() - t0

        # 2. Kimi Delta Attention (Recursive State Update)
        t0 = time.perf_counter()
        S = torch.zeros(dim, dim)
        decay = 0.95
        outputs = []
        for t in range(seq_len):
            q_t, k_t, v_t = Q[t], K[t], V[t]
            pred_v = torch.matmul(S, k_t)
            delta_v = v_t - pred_v
            S = decay * S + torch.outer(delta_v, k_t)
            y_t = torch.matmul(S, q_t)
            outputs.append(y_t)
        out_delta = torch.stack(outputs)
        t_delta = time.perf_counter() - t0

        ratio = t_quad / t_delta if t_delta > 0 else 1.0
        print(f"{seq_len:<10} | {t_quad * 1000:<18.2f} ms | {t_delta * 1000:<16.2f} ms | {ratio:<8.2f}x")

if __name__ == "__main__":
    benchmark_attention_scaling()
