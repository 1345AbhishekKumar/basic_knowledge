Kimi K3 achieves this by combining three core breakthroughs:

Pillar 01

2.8T Extreme Sparse MoE

896 total experts with dynamic top-16 routing (~50B awake parameters per token), giving the model massive global capacity at high execution speeds.

Pillar 02 · Breakthrough

Kimi Delta Attention (KDA)

Replaces $O(N^2)$ all-to-all pairwise attention with an $O(N)$ recursive exponential moving average, unlocking linear scaling across 1M token contexts.

Pillar 03

Attention Residuals & Loop Caching

Specifically optimized for agentic harnesses by caching and reusing activations from prior loop iterations, lowering costs by up to 10×.

3. Comprehensive Concept Definitions (Lesson Elements)

Every architectural mechanism, mathematical concept, and benchmark entity mentioned in the lesson is formally defined below:

KIMI K3 ARCHITECTURE

Moonshot AI's 2.8 Trillion parameter mixture-of-experts model designed specifically for long-horizon agentic workflows, long-context code navigation, and low-latency local tool execution loops.

1.78% ACTIVE EXPERT SPARSITY

An extreme sparse Mixture-of-Experts (MoE) configuration consisting of 896 total feed-forward experts. A learned router dynamically activates only the top-16 experts per token (~50B active parameters), providing massive parameter capacity while maintaining inference latency comparable to a 50B dense model.

QUADRATIC SOFTMAX ATTENTION (O(N²))

The standard transformer attention mechanism where every token attends to all prior tokens via an $N \times N$ matrix calculation $\text{Softmax}(QK^T/\sqrt{d})V$. At 1 Million tokens, compute and memory scale quadratically, creating an insurmountable bottleneck for iterative agent loops.

KIMI DELTA ATTENTION (KDA) (O(N))

A linear-time attention mechanism that eliminates the $N \times N$ matrix. It updates a fixed-size hidden memory state recursively via an exponential moving average with learned delta update gates: $S_t = \alpha_t S_{t-1} + \beta_t (K_t^T V_t)$, enabling constant-time per-token decoding across 1M+ token contexts.

KV CACHE COMPRESSION & DECAY

Instead of appending new key and value tensors linearly to RAM until GPU memory exhausts, Delta Attention compresses incoming keys and values into a recurrent hidden state matrix using a decay factor $\alpha_t$, maintaining a flat memory footprint regardless of prompt length.

ATTENTION RESIDUALS & LOOP CACHING

An optimization tailored for autonomous agent loops. Because agent turns share extensive static prefixes (system prompt, schemas, previous tool definitions), Kimi K3 preserves and reuses hidden state activations between loop turns, reducing computational costs by up to 10×.

WAKU AGENT HARNESS (BENCHMARK ARENA)

A standardized, local testing environment where 10 leading frontier models were evaluated under identical conditions across four agentic challenges: Calendar API scheduling, Pokémon semantic memory extraction, web scraping, and Python subagent coders.

GPT-5.6 SOUL (IMPARTIAL REFEREE)

An automated, blind LLM-as-a-Judge protocol. It grades execution traces across four objective axes (semantic accuracy, tool syntax compliance, loop efficiency, and hallucination absence) on a 1-to-10 scale without knowing which model generated the response.

HETEROGENEOUS TOOL-CALLING BEHAVIOR

The observed divergence in model problem-solving strategies under identical prompts: smaller, faster models (e.g. Gemini Flash) tend toward single-shot broad queries, while deeper reasoning models (Grok 4.5, Opus 4.8, Kimi K3) initiate recursive multi-turn search chains.

4. Step-by-Step Architectural Flow: The Kimi K3 Pipeline

Tracing how a token moves through Kimi K3's sparse MoE and linear Delta Attention architecture:

  1. 1

    Input Token Embedding & Residual Context Injection

    Incoming tokens are projected into high-dimensional hidden space. If running within an ongoing agent loop, the harness pre-loads the cached attention residuals from the prior turn, skipping redundant prefix computations.

  2. 2

    Kimi Delta Attention (Linear Recurrence)

    Rather than performing quadratic dot-product comparisons across all 1M historical tokens, the token updates the compact recurrent state $S_t$ in $O(1)$ time per token step, producing context-rich representations without KV cache memory blowup.

  3. 3

    Learned Token Router (MoE Dispatch)

    The token vector passes through a gating network that evaluates all 896 specialized experts, assigning softmax routing weights to only the top-16 highest-affinity experts (1.78% active parameter budget).

  4. 4

    Top-16 Expert Forward Computation

    The 16 selected expert feed-forward blocks execute in parallel. The remaining 880 experts remain asleep, preserving memory bandwidth and compute resources while maintaining 2.8T global parameter knowledge.

  5. 5

    Weighted Expert Aggregation & Output Projection

    Outputs from the 16 awake experts are multiplied by their gating weights, combined with the residual stream, and projected into the vocabulary distribution to emit the next token or structured tool call.

5. Concrete Implementation Blueprint: Softmax Attention vs. Linear Delta Attention

The Python implementation below illustrates the mathematical difference between standard quadratic $O(N^2)$ attention and Kimi's linear $O(N)$ Delta Attention with recurrent memory: 

import torch
import torch.nn as nn
import torch.nn.functional as F

# ===============================================================
# 1. STANDARD QUADRATIC ATTENTION: O(N^2) COMPLEXITY
# ===============================================================
class QuadraticSoftmaxAttention(nn.Module):
    def __init__(self, d_model: int):
        super().__init__()
        self.d_model = d_model
        self.scale = 1.0 / (d_model ** 0.5)

    def forward(self, Q: torch.Tensor, K: torch.Tensor, V: torch.Tensor):
        # Q, K, V shape: [batch, seq_len, d_model]
        # Pairwise matrix multiplication scales with seq_len^2: O(N^2)
        scores = torch.bmm(Q, K.transpose(1, 2)) * self.scale  # [B, N, N]
        attn_weights = F.softmax(scores, dim=-1)
        output = torch.bmm(attn_weights, V)                    # [B, N, d_model]
        return output

# ===============================================================
# 2. KIMI DELTA ATTENTION (KDA): O(N) LINEAR RECURRENCE
# ===============================================================
class KimiDeltaAttention(nn.Module):
    def __init__(self, d_model: int):
        super().__init__()
        self.d_model = d_model
        # Learned gate parameters for decay and update
        self.alpha_gate = nn.Linear(d_model, d_model)
        self.beta_gate = nn.Linear(d_model, d_model)

    def forward(self, Q: torch.Tensor, K: torch.Tensor, V: torch.Tensor):
        # Q, K, V shape: [batch, seq_len, d_model]
        B, N, D = Q.shape
        # Recurrent state matrix: constant size [B, D, D] regardless of sequence length!
        S = torch.zeros(B, D, D, device=Q.device)
        outputs = []

        for t in range(N):
            q_t = Q[:, t, :].unsqueeze(1)    # [B, 1, D]
            k_t = K[:, t, :].unsqueeze(2)    # [B, D, 1]
            v_t = V[:, t, :].unsqueeze(1)    # [B, 1, D]

            # Compute learned retention factors (alpha) and update gates (beta)
            alpha = torch.sigmoid(self.alpha_gate(q_t)).transpose(1, 2)  # [B, D, 1]
            beta = torch.sigmoid(self.beta_gate(q_t)).transpose(1, 2)   # [B, D, 1]

            # Recurrent state update: S_t = alpha * S_{t-1} + beta * (k_t * v_t)
            outer_product = torch.bmm(k_t, v_t)                         # [B, D, D]
            S = alpha * S + beta * outer_product

            # Compute output token: y_t = q_t * S_t -> Constant O(1) step!
            y_t = torch.bmm(q_t, S)                                      # [B, 1, D]
            outputs.append(y_t)

        return torch.cat(outputs, dim=1)  # Overall complexity: O(N) linear!

# Verification & Benchmarking
if __name__ == "__main__":
    B, SeqLen, Dim = 2, 512, 64
    Q = torch.randn(B, SeqLen, Dim)
    K = torch.randn(B, SeqLen, Dim)
    V = torch.randn(B, SeqLen, Dim)

    quad_attn = QuadraticSoftmaxAttention(Dim)
    delta_attn = KimiDeltaAttention(Dim)

    out_quad = quad_attn(Q, K, V)
    out_delta = delta_attn(Q, K, V)

    print(f"[✓] Quadratic Attention Output Shape: {out_quad.shape} (Computed in O(N^2))")
    print(f"[✓] Kimi Delta Attention Output Shape: {out_delta.shape} (Computed in O(N) linear time)")
