Kimi K3: Sparse MoE, Delta Attention & Agentic Coding

How Moonshot AI's 2.8T parameter model bypasses the quadratic transformer wall with 1.78% active expert sparsity, linear Delta Attention, and loop token caching—benchmarked across 10 frontier models in a local agent harness.

1. The Architectural Triad: Why Kimi K3 Blew Up

Frontier AI models are entering a new phase where raw parameter count alone is insufficient. Long-horizon agentic coding demands models that can swallow 1 Million tokens of context, execute multi-turn tool loops, and maintain affordable inference economics.

Kimi K3 achieves this by combining three core breakthroughs:

Pillar 01

2.8T Extreme Sparse MoE

896 total experts with dynamic top-16 routing (~50B awake parameters per token), giving the model massive global capacity at high execution speeds.

Pillar 02 · Breakthrough

Kimi Delta Attention (KDA)

Replaces $O(N^2)$ all-to-all pairwise attention with an $O(N)$ recursive exponential moving average, unlocking linear scaling across 1M token contexts.

Pillar 03

Attention Residuals & Loop Caching

Specifically optimized for agentic harnesses by caching and reusing activations from prior loop iterations, lowering costs by up to 10×.

"Instead of recalculating an entire 10,000-word history from scratch at every step, Delta Attention updates a running mean in linear time—transforming how agents loop over code."

— Core Architectural Insight

2. Empirical Findings from the 10-Model Harness Arena

In a rigorous empirical test on the local Waku Agent harness using GPT-5.6 Soul as an impartial referee across real-world tasks (Calendar APIs, Pokémon semantic memory, Web scrapers, and Python subagent coders):

Key Benchmark Takeaways

  • Top Reasoning Performers: xAI Grok 4.5 led the scoreboard at 8.3 / 10, followed closely by Claude Opus 4.8 (7.9), Kimi K2.7 (7.6), and Kimi K3 (7.5).
  • The Token Cost Divide: Claude Opus 4.8 consumed nearly double the token budget of Kimi models, resulting in the highest cost tier. Kimi K2.7 and K3 delivered competitive quality at significantly lower financial expense.
  • Tool Calling Behavior: Even under identical harness prompts, models behaved heterogeneously—Gemini Flash prioritized fast single searches, while others executed iterative web lookups.
