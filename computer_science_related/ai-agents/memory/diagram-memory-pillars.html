The 3 Cognitive Pillars of AI Agent Memory

How an agent harness bridges stateless LLM executions into a persistent cognitive system using procedural routines, durable semantic facts, and episodic event history.

1. Core Component Definitions

Exhaustive definitions of all memory pillars, runtime components, and architectural gates illustrated in the diagram:

1. Procedural Memory Trigger Loaded

Operational procedures, prompt heuristics, personas (SOUL.md), and specialized tool skills. Informs the runtime on how to act, execute commands, and handle errors. Loaded dynamically on relevant triggers.

2. Semantic Memory Consolidated Core

Durable truths, verified domain facts, user preferences, and project context (MEMORY.md). Informs the runtime on what is true across all sessions without parsing raw chat histories.

3. Episodic Memory Time Indexed

Timestamped logs of interaction history, prompt-response pairs, tool arguments, and environmental outputs (SQLite state.db). Informs the runtime on what occurred and when.

Retrieval Gate Selective Filter

An algorithmic gatekeeper that evaluates context window token limits and selectively injects relevant procedural skills and semantic facts while preventing context saturation.

Consolidation Engine Dreaming Daemon

An asynchronous background process running an auxiliary LLM during idle intervals. Scans episodic turns, resolves contradictions, extracts durable facts, and writes updates into semantic memory.

Active Working Memory Context Window

The dynamic RAM of the agent for the current turn. Combines the System Persona (Soul) + Active Skills + Preloaded Facts + Recent Turn Messages into a single token budget.

Agent Execution Loop Reasoning Engine

The cognitive loop that evaluates user instructions, executes tools, spawns autonomous subagents, and generates responses while streaming telemetry to episodic logs.

External I/O & Environment System Hooks

The interface to external tools and user interactions: Terminal bash commands, Model Context Protocol (MCP) servers, web scrapers, local file systems, and chat UI prompts.

2. Step-by-Step Diagram Flow Walkthrough

Tracing the directional flow and lifecycle connectors between storage, runtime, and the background consolidation daemon:

1
Storage to Retrieval Gate: Selective Ingestion

Persistent Cognitive Storage (Procedural skills and Semantic facts) feeds into the Retrieval Gate via the slate and coral arrows. The gate calculates available context budget and discards irrelevant facts.

2
Retrieval Gate to Active Working Memory

Filtered procedural instructions (e.g. SOUL.md) and durable facts (e.g. user preferences) are piped into Active Working Memory, assembling the full prompt context for the turn.

3
Working Memory to Execution Loop

The assembled prompt context passes down the ink arrow into the Agent Execution Loop. The model decides whether tool calling or subagent spawning is required to fulfill the user's objective.

4
Execution Loop to External I/O Interaction

The execution engine invokes MCP tools, executes bash scripts in the terminal, or dispatches subagents, collecting live environmental results and generating a reply to the user.

5
Execution Loop to Episodic Storage: Logging Turn

The left-directed slate arrow logs the full execution record (raw prompt, tool inputs/outputs, error logs, final text) into Episodic Memory (SQLite state.db) with precise millisecond timestamps.

6
Episodic to Consolidation to Semantic: The Dreaming Loop

The dashed arrows complete the cognitive lifecycle: the Consolidation Engine ("Dreaming") ingests uncompressed episodic turns during idle time, distills new facts via an auxiliary LLM, and writes reconciled truths back into Semantic Memory.

3. Concrete Implementation Blueprint

A runnable Python blueprint demonstrating the complete 3-pillar memory system and its bidirectional consolidation loop:

three_pillars_memory_harness.py — Dual-Loop Cognitive Architecture Python 3.11+ / SQLite 
import sqlite3
import time
import asyncio
from dataclasses import dataclass
from typing import List, Dict, Any, Optional

# =============================================================
# PILLAR 1: PROCEDURAL MEMORY (Skills & SOUL.md Persona)
# =============================================================
class ProceduralStore:
    def __init__(self):
        self.soul_md = "You are Hermes, an autonomous research agent."
        self.skills = {
            "web_scrape": "SOP: Extract markdown without html boilerplate.",
            "code_review": "SOP: Identify architectural bottlenecks first."
        }

    def retrieve_persona_and_skill(self, trigger: str) -> str:
        skill = self.skills.get(trigger, "")
        return f"{self.soul_md}\nActive Procedure: {skill}" if skill else self.soul_md

# =============================================================
# PILLAR 2: SEMANTIC MEMORY (MEMORY.md & Durable Truths)
# =============================================================
class SemanticStore:
    def __init__(self):
        self.facts: Dict[str, str] = {
            "user_name": "Abhishek",
            "active_project": "AI Agent Architecture Curriculum"
        }

    def get_all_facts(self) -> List[str]:
        return [f"{k}: {v}" for k, v in self.facts.items()]

    def update_fact(self, key: str, value: str):
        print(f"[Semantic Store] Consolidated Fact Updated: {key} -> '{value}'")
        self.facts[key] = value

# =============================================================
# PILLAR 3: EPISODIC MEMORY (SQLite Turn Logging)
# =============================================================
class EpisodicStore:
    def __init__(self):
        self.conn = sqlite3.connect(":memory:")
        with self.conn:
            self.conn.execute(
                "CREATE TABLE turns (id INTEGER PRIMARY KEY, role TEXT, content TEXT, ts REAL)"
            )

    def log(self, role: str, content: str):
        with self.conn:
            self.conn.execute("INSERT INTO turns (role, content, ts) VALUES (?, ?, ?)",
                              (role, content, time.time()))

    def fetch_recent(self, limit: int = 5) -> List[Dict[str, Any]]:
        cur = self.conn.execute("SELECT role, content FROM turns ORDER BY id DESC LIMIT ?", (limit,))
        return [{"role": r[0], "content": r[1]} for r in cur.fetchall()]

# =============================================================
# RETRIEVAL GATE & AGENT HARNESS
# =============================================================
class AgentHarness:
    def __init__(self):
        self.procedural = ProceduralStore()
        self.semantic = SemanticStore()
        self.episodic = EpisodicStore()

    def retrieval_gate(self, user_prompt: str) -> str:
        # Construct active working memory budget
        persona = self.procedural.retrieve_persona_and_skill("code_review")
        facts = "\n".join(self.semantic.get_all_facts())
        return f"=== SYSTEM CONTEXT ===\n{persona}\n\n=== DURABLE FACTS ===\n{facts}\n"

    def execute_online_turn(self, user_prompt: str) -> str:
        # Step 1: Retrieval gate builds Working Memory
        working_memory = self.retrieval_gate(user_prompt)
        print(f"\n[Online Execution] Prompting with Working Memory:\n{working_memory}")
        
        # Step 2: Log user turn to episodic
        self.episodic.log("user", user_prompt)
        
        # Step 3: Simulate execution and response
        response = f"Analyzed your request regarding '{user_prompt}' with active context."
        self.episodic.log("assistant", response)
        return response

    async def consolidation_dreaming_daemon(self):
        """Offline dreaming loop extracting durable facts from episodic turns."""
        print("\n[Dreaming Daemon] Triggering idle consolidation across recent turns...")
        await asyncio.sleep(0.4)
        turns = self.episodic.fetch_recent(10)
        
        # Extract new facts from episodic turns
        for t in turns:
            if t["role"] == "user" and "i am learning" in t["content"].lower():
                topic = t["content"].split("learning")[-1].strip()
                self.semantic.update_fact("current_topic", topic)
        print("[Dreaming Daemon] Distillation complete. Cognitive loop closed.\n")

# =============================================================
# DEMO EXECUTION
# =============================================================
async def main():
    agent = AgentHarness()
    
    # Online turn 1
    agent.execute_online_turn("Hello, I am learning Graph Engineering today.")
    
    # Idle consolidation "Dreaming" loop
    await agent.consolidation_dreaming_daemon()
    
    # Online turn 2: Working Memory will now contain the newly learned topic
    agent.execute_online_turn("What is my active topic?")

if __name__ == "__main__":
    asyncio.run(main())
