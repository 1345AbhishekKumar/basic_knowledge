Temporal Invalidation & The Consolidation "Dreaming" Loop

How modern agent harnesses manage evolving truth over time—superseding historical records without data loss, and running idle-time consolidation.

1. Core Component Definitions

Exhaustive definitions of all temporal lifecycle concepts, invalidation mechanisms, and dreaming stages illustrated in the diagram:

Naive Overwrite (Anti-Pattern) Destructive

Directly deleting or overwriting previous records in place when values update (e.g. replacing 1,000 GitHub stars with 1,300 stars). Flaw: Destroys trend telemetry, rate-of-change metrics (+30% velocity in 24h), and audit history.

Temporal Superseding Non-Destructive

The industry-standard truth maintenance protocol. Rather than deleting an older fact, it records an end timestamp (valid_to = now) and inserts the new fact with an active timestamp (valid_to = NULL).

Epoch t0 (Superseded State) Historical Truth

A fact that was true during a specific past window (e.g. "Elon will arrive at 7:00 PM", valid from 18:00 to 18:45). Remains accessible for historical postmortems explaining why plans shifted.

Epoch t1 (Active Truth) Current Truth

The currently active assertion (e.g. "Elon will arrive at 9:00 PM", valid from 18:45 to NOW). Active runtime queries filter strictly for records where valid_to IS NULL.

1. Online Interaction (High Velocity) Stage 1

The customer-facing agent execution loop. Prioritizes raw speed and responsiveness by appending raw conversation turns and tool outputs directly into SQLite without pause.

2. Idle Consolidation ("Dreaming") Stage 2

An off-peak background batch process powered by an auxiliary model. Scans unmerged turns, filters conversational filler, aggregates duplicate entities, and resolves conflicting temporal timestamps.

3. Durable Semantic Output Stage 3

The consolidated product of dreaming: atomic, unambiguous markdown bullet points (MEMORY.md) or knowledge graph triples ready for immediate prompt injection on subsequent turns.

Dreaming Feedback Loop Cognitive Cycle

The dashed connector closing the loop: freshly distilled semantic facts are loaded into the agent's prompt context for the next online turn, ensuring continuous learning across sessions.

2. Step-by-Step Diagram Flow Walkthrough

Tracing the operational mechanics of both panels of the diagram:

1
Section A — Case 1: The Failure of Naive Overwrites

On Day 25, Waku reaches 1,000 stars. On Day 26, it reaches 1.3k stars. A naive system executes an in-place UPDATE or DELETE, wiping Day 25. When the user asks "What is our star growth velocity?", the agent has lost all prior baseline context.

2
Section A — Case 2: Non-Destructive Temporal Superseding

At 18:00 (Epoch t0), the fact "Elon arrives at 7:00 PM" is committed. At 18:45 (Epoch t1), a new update arrives. The harness sets Epoch t0's valid_to = 18:45 and inserts Epoch t1 with valid_to = NULL. Active queries pull 9:00 PM; historical queries explain why the schedule shifted.

3
Section B — Stage 1: High-Velocity Online Logging

During user interaction, the agent does not block on heavy LLM reasoning for memory. It streams tool execution logs and raw conversation turns directly into state.db, keeping latency minimal.

4
Section B — Stage 2: Off-Peak Consolidation ("Dreaming")

When the user disconnects or pauses, the Consolidation Daemon triggers. An auxiliary LLM filters greetings ("Hi, thanks!"), unifies multiple mentions of the same entity, and applies temporal validity bounds.

5
Section B — Stage 3: Closed-Loop Semantic Persistence

The distilled truths are written to MEMORY.md. The dashed line loops back to Stage 1: on the next turn, the agent retrieves this updated semantic truth with zero extra turn latency.

3. Concrete Implementation Blueprint

A runnable Python blueprint demonstrating non-destructive temporal superseding and an asynchronous dreaming consolidation loop:

temporal_invalidation_dreaming.py — Production Lifecycle Harness Python 3.11+ / SQLite 
import sqlite3
import time
import asyncio
from typing import List, Dict, Any, Optional

class TemporalMemorySystem:
    def __init__(self, db_path=":memory:"):
        self.conn = sqlite3.connect(db_path)
        self.init_db()

    def init_db(self):
        with self.conn:
            # 1. Episodic Raw Turns
            self.conn.execute("""
                CREATE TABLE IF NOT EXISTS episodic_turns (
                    id INTEGER PRIMARY KEY AUTOINCREMENT,
                    role TEXT,
                    content TEXT,
                    created_at REAL,
                    consolidated INTEGER DEFAULT 0
                )
            """)
            # 2. Semantic Facts with Temporal Validity Intervals
            self.conn.execute("""
                CREATE TABLE IF NOT EXISTS semantic_facts (
                    id INTEGER PRIMARY KEY AUTOINCREMENT,
                    entity TEXT,
                    property TEXT,
                    value TEXT,
                    valid_from REAL,
                    valid_to REAL -- NULL means currently active truth
                )
            """)

    # =========================================================
    # SECTION A: TEMPORAL SUPERSEDING (Non-Destructive)
    # =========================================================
    def update_fact_temporal(self, entity: str, prop: str, new_val: str):
        now = time.time()
        with self.conn:
            # Invalidate currently active version
            self.conn.execute(
                "UPDATE semantic_facts SET valid_to = ? WHERE entity = ? AND property = ? AND valid_to IS NULL",
                (now, entity, prop)
            )
            # Insert new active version
            self.conn.execute(
                "INSERT INTO semantic_facts (entity, property, value, valid_from, valid_to) VALUES (?, ?, ?, ?, NULL)",
                (entity, prop, new_val, now)
            )
        print(f"[Temporal Supersede] {entity}.{prop} updated to '{new_val}' at ts={now:.2f}")

    def get_current_truth(self, entity: str, prop: str) -> Optional[str]:
        cur = self.conn.execute(
            "SELECT value FROM semantic_facts WHERE entity = ? AND property = ? AND valid_to IS NULL",
            (entity, prop)
        )
        row = cur.fetchone()
        return row[0] if row else None

    def get_history_telemetry(self, entity: str, prop: str) -> List[Dict[str, Any]]:
        cur = self.conn.execute(
            "SELECT value, valid_from, valid_to FROM semantic_facts WHERE entity = ? AND property = ? ORDER BY valid_from ASC",
            (entity, prop)
        )
        return [{"value": r[0], "from": r[1], "to": r[2]} for r in cur.fetchall()]

    # =========================================================
    # SECTION B: CONSOLIDATION "DREAMING" WORKER
    # =========================================================
    def log_online_turn(self, role: str, message: str):
        with self.conn:
            self.conn.execute(
                "INSERT INTO episodic_turns (role, content, created_at) VALUES (?, ?, ?)",
                (role, message, time.time())
            )

    async def run_dreaming_consolidation(self):
        print("\n[Dreaming Worker] Scanning unmerged episodic turns...")
        await asyncio.sleep(0.3)
        with self.conn:
            cur = self.conn.execute(
                "SELECT id, content FROM episodic_turns WHERE consolidated = 0"
            )
            turns = cur.fetchall()
            
            for turn_id, content in turns:
                # Simulated entity & fact extraction
                if "dinner" in content.lower() and "arrive at" in content.lower():
                    time_str = content.split("arrive at")[-1].strip().rstrip(".")
                    self.update_fact_temporal("DinnerEvent", "arrival_time", time_str)
                
                # Mark turn as consolidated
                self.conn.execute("UPDATE episodic_turns SET consolidated = 1 WHERE id = ?", (turn_id,))
        print("[Dreaming Worker] Batch distillation finished.\n")

if __name__ == "__main__":
    memory = TemporalMemorySystem()

    # Turn 1: Initial event schedule
    memory.log_online_turn("user", "Elon Musk will arrive at 7:00 PM for the dinner party.")
    asyncio.run(memory.run_dreaming_consolidation())

    # Turn 2: Schedule changes
    time.sleep(0.05)
    memory.log_online_turn("user", "Elon Musk updated arrival time: will arrive at 9:00 PM.")
    asyncio.run(memory.run_dreaming_consolidation())

    # Query Active Truth
    active_time = memory.get_current_truth("DinnerEvent", "arrival_time")
    print(f"Active Truth for Dinner Arrival: {active_time}")

    # Query History (demonstrating zero loss of telemetry)
    print("Historical Evolution Telemetry:")
    for record in memory.get_history_telemetry("DinnerEvent", "arrival_time"):
        status = "ACTIVE" if record["to"] is None else f"SUPERSEDED at {record['to']:.2f}"
        print(f"• Value: '{record['value']}' | Status: {status}")
