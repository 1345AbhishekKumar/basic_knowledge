Detailed Architectural Explanations

Headless Mode

Why Single-Shot `pi -p` is a Game Changer

Outer agent harnesses (like Waku Agent or OpenClaw) don't need a terminal GUI; they need an obedient, ultra-fast coding subprocess. With pi -p "write Pokémon script", the parent harness spawns a child process that runs the four tools, generates the script, and returns the raw output to stdout in seconds.

Telemetry & Streaming

`--mode json` for Observability

By passing --mode json, Pi Agent outputs structured event packets per thinking step, tool invocation, and token calculation. This allows real-time UI progress bars and seamless ingestion into LLMOps tracing platforms like LangSmith or Langfuse without parsing terminal ANSI codes.
