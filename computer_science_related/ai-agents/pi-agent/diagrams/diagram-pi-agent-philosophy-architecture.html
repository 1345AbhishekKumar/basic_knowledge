Core Philosophy

The Power of "What We Did NOT Build"

Most coding assistants suffer from feature bloat: complex planning modes, intrusive permission pop-ups, and heavy MCP servers that inject tens of thousands of unused tokens into the prompt. Pi Agent strips away all bloat, executing a razor-sharp 792-line core loop with only four fundamental file/system operations.

The 4 Core Actions

read, write, edit, and bash

Every complex programming task—from refactoring code to executing unit tests—reduces down to four primitives: read (inspect files), write (generate files), edit (modify lines in-place), and bash (run terminal commands). By restricting the toolbelt to these 4 primitives, the LLM maintains maximum focus and zero hallucinated tool calls.
