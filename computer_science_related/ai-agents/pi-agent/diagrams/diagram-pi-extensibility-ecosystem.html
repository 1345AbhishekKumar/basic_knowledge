Tier 01 & 02

Skills vs. TypeScript Extensions

Skills are markdown SOPs that instruct the model how to query existing APIs. Extensions are native TypeScript files stored in ~/.pi/extensions/ that inject brand-new, executable tool functions into Pi's runtime without the heavy overhead of external MCP daemon processes.

Tier 04 · The Universal Subagent

Plugging Pi into Outer Harnesses

Because Pi Agent has a lightning-fast CLI interface (pi -p), it serves as the default headless coding engine for outer agent orchestrators like Waku Agent and OpenClaw. The outer agent manages memories, gateways, and evals, while delegating code synthesis to Pi Agent.
