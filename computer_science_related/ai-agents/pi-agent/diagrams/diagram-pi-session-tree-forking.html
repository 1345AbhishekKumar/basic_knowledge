Detailed Architectural Explanations

Version Control

Why Sessions are Directed Trees

Traditional chat assistants store conversation history as a flat, linear array. When you backtrack or rewrite a prompt, previous turns are permanently erased. Pi Agent structures session history as a Directed Acyclic Tree saved in local JSON files under ~/.pi/sessions/.

Developer Power Tool

The `/fork` Slash Command

By typing /fork inside the TUI, developers can jump back to any historical turn and spawn an alternative branch (e.g. testing an async vs. sync implementation of a Python function) without destroying the original working tree.
