Session Tree Architecture & Conversational Forking

How Pi Agent stores local JSON session trees inside `~/.pi/sessions/` to enable `/fork` branching—allowing developers to explore alternative coding strategies without losing history.

FIGURE 3.0 — PI AGENT SESSION TREE & CONVERSATIONAL FORKING ARCHITECTURE

Detailed Architectural Explanations

Version Control

Why Sessions are Directed Trees

Traditional chat assistants store conversation history as a flat, linear array. When you backtrack or rewrite a prompt, previous turns are permanently erased. Pi Agent structures session history as a Directed Acyclic Tree saved in local JSON files under ~/.pi/sessions/.

Developer Power Tool

The `/fork` Slash Command

By typing /fork inside the TUI, developers can jump back to any historical turn and spawn an alternative branch (e.g. testing an async vs. sync implementation of a Python function) without destroying the original working tree.

1. Session Tree Definitions

Formal definitions for every node, branch, and storage concept depicted in Figure 3.0:

Graph Data Structure

Conversational Tree Graph

Pi Agent's internal representation of chat history as a Directed Acyclic Graph (DAG) saved in ~/.pi/sessions/<id>.json. Each message turn is an explicit node containing a unique UUID, a pointer to its parent_id, role, timestamp, and content payloads.

Branching Primitive

The /fork Command

A built-in TUI command that redirects the session's active leaf pointer to any previous node in the tree. Subsequent messages create a new child branch, preserving all parallel conversation histories without destructive overwrites.

Tree Structure

Main Trunk vs Branch A

The Main Trunk represents the default forward linear progression of turns (e.g. Turn 01 → Turn 02 → Turn 03). Branch A represents a divergent exploration spawned from an earlier decision point (e.g. Turn 01 → Branch A Turn 02).

Developer Workflow

Non-Destructive Exploration

The architectural guarantee that backtracking never deletes code or prompt context. Developers can test risky architectural refactors on Branch A, inspect diffs, and switch back to the Main Trunk without losing a single character.

Storage Protocol

Local-First JSON Persistence

All session data resides on the developer's local filesystem in ~/.pi/sessions/. With zero external cloud database dependencies, sessions remain privately owned, fully offline-accessible, and easily indexable via standard Unix command-line tools like grep or jq.

2. Step-by-Step Diagram Flow Walkthrough

Tracing the conversational branching and fork mechanics illustrated in Figure 3.0:

1

Root Node Creation (Turn 01)

The session initiates with user prompt: "Tell me a yellow Pokémon." Pi writes Node 1 with parent_id: null to the session JSON file on local disk.

2

Main Trunk Linear Progression (Turns 02 & 03)

Pi responds with Turn 02: "Pikachu (Electric Type)" (points to Node 1). The user continues on the main trunk with Turn 03: "What are Pikachu's stats?" (points to Node 2). The active pointer rests at Node 3.

3

Issuing the /fork Command

The developer decides to explore an alternative path and runs /fork 1. Pi resets its active pointer back to Node 1 without modifying or deleting Node 2 or Node 3.

4

Branch A Spawning & Divergence

The developer enters: "Must not be electric type!". Pi creates Branch A Node 2 pointing to Node 1, yielding "Psyduck (Water) or Zapdos", followed by Branch A Turn 03: "Write a Python script for Psyduck."

5

Disk Persistence & Branch Traversal

Both paths remain fully intact on disk. When assembling prompt context, Pi simply walks backward from the active leaf pointer to the root, generating the exact conversation path for the current branch.

3. Implementation Blueprint: Local DAG Session Tree

Clean Python implementation of Pi Agent's directed acyclic tree storage with /fork support:

pi_session_tree.py · DAG Session Version Control Engine
import json
import os
import time
from typing import Dict, List, Optional, Any

class SessionNode:
    def __init__(self, node_id: str, parent_id: Optional[str], role: str, content: str):
        self.node_id = node_id
        self.parent_id = parent_id
        self.role = role
        self.content = content
        self.timestamp = time.time()

    def to_dict(self) -> Dict[str, Any]:
        return {
            "node_id": self.node_id,
            "parent_id": self.parent_id,
            "role": self.role,
            "content": self.content,
            "timestamp": self.timestamp
        }

class PiDAGSession:
    def __init__(self, session_id: str, storage_dir: str = "~/.pi/sessions/"):
        self.session_id = session_id
        self.storage_path = os.path.expanduser(os.path.join(storage_dir, f"{session_id}.json"))
        self.nodes: Dict[str, SessionNode] = {}
        self.active_node_id: Optional[str] = None
        self._load_or_init()

    def _load_or_init(self) -> None:
        if os.path.exists(self.storage_path):
            with open(self.storage_path, "r", encoding="utf-8") as f:
                data = json.load(f)
                self.active_node_id = data.get("active_node_id")
                for item in data.get("nodes", []):
                    node = SessionNode(item["node_id"], item["parent_id"], item["role"], item["content"])
                    node.timestamp = item["timestamp"]
                    self.nodes[node.node_id] = node

    def save(self) -> None:
        os.makedirs(os.path.dirname(self.storage_path), exist_ok=True)
        payload = {
            "session_id": self.session_id,
            "active_node_id": self.active_node_id,
            "nodes": [n.to_dict() for n in self.nodes.values()]
        }
        with open(self.storage_path, "w", encoding="utf-8") as f:
            json.dump(payload, f, indent=2)

    def append_turn(self, role: str, content: str) -> str:
        """Appends a turn to the current branch tip."""
        node_id = f"turn_{len(self.nodes) + 1:03d}"
        node = SessionNode(node_id, self.active_node_id, role, content)
        self.nodes[node_id] = node
        self.active_node_id = node_id
        self.save()
        return node_id

    def fork(self, target_turn_id: str) -> None:
        """Non-destructively points active tip to an ancestor turn."""
        if target_turn_id not in self.nodes:
            raise KeyError(f"Target node {target_turn_id} not found in tree.")
        self.active_node_id = target_turn_id
        self.save()

    def get_active_branch_history(self) -> List[Dict[str, str]]:
        """Traverses upward from active node to root to assemble linear prompt context."""
        history = []
        curr = self.active_node_id
        while curr is not None:
            node = self.nodes[curr]
            history.append({"role": node.role, "content": node.content})
            curr = node.parent_id
        return list(reversed(history))

# Demonstration of the Figure 3.0 scenario
if __name__ == "__main__":
    session = PiDAGSession("pokemon_demo")
    t1 = session.append_turn("user", "Tell me a yellow Pokémon.")
    t2 = session.append_turn("assistant", "Pikachu (Electric Type)")
    t3 = session.append_turn("user", "What are Pikachu's stats?")

    # Fork back to Turn 01 to explore Branch A
    session.fork(t1)
    b2 = session.append_turn("user", "Must not be electric type!")
    b3 = session.append_turn("assistant", "Psyduck (Water type)")

    print(f"Active Branch Context: {session.get_active_branch_history()}")
    print(f"Total Nodes Preserved on Disk: {len(session.nodes)}")
