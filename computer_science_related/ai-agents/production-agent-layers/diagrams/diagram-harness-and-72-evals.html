Harness Engineering

What is an Agent Harness?

The agent harness is the operational scaffolding wrapped around the model. It handles Pre-flight validation (sanitizing schemas, verifying auth), Runtime Governance (state management, circuit breakers, distributed tracing), and Post-flight compliance (auditing outputs before reaching end-users).

Evaluation Harness

The 72-Eval Suite for Enterprise Claims

To prevent catastrophic hallucinations (such as approving $4,500 on a $300 scratch), Maryam's insurance claim architecture runs 72 automated unit evals covering image mismatch detection, policy limit enforcement, risk score escalation, and immutable audit trails in CI/CD pipelines.

Harness Subsystem 02

Managed Execution & Circuit Breakers

Controls graph execution dynamics. Automatically captures state snapshots after each node, tracks distributed telemetry spans, enforces token consumption caps, and activates circuit breakers to kill loops if retries exceed threshold.

Harness Subsystem 03

The egress compliance firewall. Asserts that generated payout decisions fall within legally mandated bounds, ensures explanation rationales are legally sound, and writes an append-only, cryptographically hashed audit entry.

Damage Evidence (18 evals): Tests computer vision consistency, camera perspective validity, and confidence thresholding. Policy Rules (18 evals): Asserts strict policy exclusion enforcement, deductible calculations, and coverage expiration checks.

Eval Suite 03 & 04

Risk/Fraud & Payout/Audit (36 Evals)

Risk & Fraud (18 evals): Validates fraud scoring escalation, multi-claim velocity alerts, and suspicious date gaps. Payout & Audit (18 evals): Enforces maximum financial caps, minimum thresholds, and ledger immutability.

Quality Gate

2. Step-by-Step Harness & Eval Lifecycle Walkthrough

Tracing the production governance and automated test pipeline depicted in Figure 4.0:

1

Step 1: Inbound Pre-Flight Sanitization

When an insurance claim payload hits the API, the Pre-Flight Gateway inspects JSON schemas, validates user JWTs, and verifies policy existence in CRM databases before instantiating the LangGraph execution state.

2

Step 2: Managed Graph Execution with Circuit Breakers

The agent graph executes under active harness supervision. If an evaluation node encounters persistent contradictions and loops more than 3 times, the harness circuit breaker fires, halting execution and routing the ticket to a human supervisor.

3

Step 3: Post-Flight Compliance Firewall & Ledger Commit

Before any funds are disbursed, the Post-Flight engine validates that the payout does not exceed user policy limits or regional maximums. It signs and logs the entire decision trajectory to an immutable audit database.

4

Step 4: Continuous CI/CD 72-Eval Test Execution

On every code commit or prompt modification, the CI pipeline runs the full 72-eval test matrix. Tests span damage discrepancies, policy exclusions, fraud thresholds, and payout boundaries. A single regression blocks production deployment.

harness_eval_runner.py · Harness Runtime Governor & Automated Eval Suite
from typing import Dict, Any, List, Callable

# ==========================================
# HARNESS RUNTIME GOVERNOR
# ==========================================
class InsuranceHarness:
    def __init__(self, hard_payout_cap: float = 5000.0, max_loop_iterations: int = 3):
        self.hard_payout_cap = hard_payout_cap
        self.max_loop_iterations = max_loop_iterations

    def run_preflight(self, claim: Dict[str, Any]) -> bool:
        if not claim.get("policy_id") or not claim.get("damage_photos"):
            return False
        return True

    def run_postflight_governance(self, proposed_payout: float, policy_max: float) -> float:
        # Enforce legal and policy boundaries
        effective_cap = min(self.hard_payout_cap, policy_max)
        if proposed_payout > effective_cap:
            return effective_cap
        return proposed_payout

# ==========================================
# 72 AUTOMATED EVALS TEST MATRIX RUNNER
# ==========================================
class EvalTestMatrix:
    def __init__(self, harness: InsuranceHarness):
        self.harness = harness
        self.results: Dict[str, str] = {}

    # Category 1: Damage Evidence Evals
    def test_image_claim_mismatch(self):
        """Eval: Detects if visual scratch contradicts massive bumper quote."""
        claim = {"description": "scratch", "cv_scratch_detected": True, "raw_quote": 4500.0}
        # In a hardened system, scratch quote must be capped or flagged
        corrected = 300.0 if claim["cv_scratch_detected"] else claim["raw_quote"]
        assert corrected == 300.0
        self.results["test_image_claim_mismatch"] = "PASS"

    # Category 2: Policy Rules Evals
    def test_excluded_coverage_flag(self):
        """Eval: Rejects payout for non-covered flood damage under basic policy."""
        policy = {"type": "basic_liability", "covers_flood": False}
        claim_cause = "flood"
        eligible = policy["covers_flood"] if claim_cause == "flood" else True
        assert eligible is False
        self.results["test_excluded_coverage_flag"] = "PASS"

    # Category 3: Risk & Fraud Evals
    def test_risk_score_escalation(self):
        """Eval: Claims filed within 24 hours of policy inception trigger fraud review."""
        hours_since_inception = 18
        fraud_risk = 0.85 if hours_since_inception < 24 else 0.10
        assert fraud_risk > 0.75
        self.results["test_risk_score_escalation"] = "PASS"

    # Category 4: Payout & Audit Evals
    def test_payout_above_limit(self):
        """Eval: Harness must cap payouts exceeding the $5000 hard ceiling."""
        capped = self.harness.run_postflight_governance(proposed_payout=7500.0, policy_max=10000.0)
        assert capped == 5000.0
        self.results["test_payout_above_limit"] = "PASS"

    def run_all_evals(self):
        tests = [
            self.test_image_claim_mismatch,
            self.test_excluded_coverage_flag,
            self.test_risk_score_escalation,
            self.test_payout_above_limit
        ]
        for t in tests:
            t()
        return self.results

if __name__ == "__main__":
    harness = InsuranceHarness(hard_payout_cap=5000.0)
    eval_suite = EvalTestMatrix(harness)
    results = eval_suite.run_all_evals()
    print("Automated Evals Suite Results:")
    for test_name, status in results.items():
        print(f"  [{status}] {test_name}")
