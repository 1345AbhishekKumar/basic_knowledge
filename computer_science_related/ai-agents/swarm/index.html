Course explanation — read this first

Why this course exists — Sean's 18-minute walk from one prompt to an organization

The transcript is not a product demo. It is a ladder. Sean starts with the only unit that must be understood before any team makes sense: a single agent answering “Who is the best AI builder and YouTuber?” That example is kept deliberately naive — one prompt, one Search API call, one biased answer — so you can see what disappears when you add handoffs, then parallelism, then autonomy. Each lesson rewinds to that same question and asks: what changes if we add a second agent, then five, then twelve that we did not name?

How the diagram above should be read

The horizontal path is wall-clock time. Left is lowest coordination cost. The first gap (Single → Sequential) adds quality through specialization but makes time additive. The coral pivot (Teams → Swarm) is the only place the system stops asking you who should do the work. Everything after that — Comparison and Live Demos — is Sean proving the trade lives in real products, not theory.

  • Left of coral — you are the org chart. Teams (Claw Code) only works if you can name teammates 1–5 and their lenses before execution. Control is maximal, breadth is bounded by your decomposition skill.
  • Right of coral — the org chart writes itself. Swarm (Kimi K2.5) discovers the decomposition from a vague goal. You trade control for breadth: 100 sub-pages claimed, 12 agents actually spawned in the demo, 10 succeeded.
  • Deep Research — the middle. Same supervisor pattern, but with a clarification + brief ceremony. Use it when you need an auditable brief before breadth.

How to use the six lessons

Do not jump to the comparison. The insight that “both reconcile dissent to avoid single-bias decisions” only lands after you have seen a sequential handoff fail on time and a team scorch 90k tokens before being steered down to 15k. Open the files in order, double-click offline, and keep the transcript timestamps nearby — L03 at 02:14 (Claw), L04 at 00:42 (Kimi), L06 at 11:02 (YouTube) and 14:30 (Automatis).
