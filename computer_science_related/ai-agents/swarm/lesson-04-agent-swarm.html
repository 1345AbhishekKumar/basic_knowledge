Agent swarm: the queen derives goals, the hive spawns itself

No human defines who does what. A goal agent derives specs (“find top 20 YouTubers by positioning”), then creates templated agents on the fly — 12 in the transcript’s demo. Each small agent runs, then a synthesizer / clustering agent merges 26 channels into opportunities. Sean’s analogy: random forest.

How It Spawns

  • Queen processes prompt → Goal agent derives specs (top 20 YouTubers)
  • Goal agent creates its own agent templates — no human pre-definition
  • 12 agents: “competitive intel researcher specializing in AI coding / automation / education…”
  • Unlike Teams: not told who does what; system decides “maybe I need 20 agents”

How It Merges

  • 10 of 12 agents completed → crowdsourced results pooled
  • “Launch clustering agent” — Bowen — called as synthesizer
  • Final layer = random forest vote: clusters 26 channels by positioning/format
  • Delivers competitive landscape — oversaturated vs white-space

Strengths & Costs

  • Handles vague intent — breaks down tasks without you specifying
  • Breadth: many parallel opinions → less bias after reconciliation
  • Batch ops: search + download + files simultaneously
  • Hungry: 2×+ tokens vs Teams; UI streaming helps track progress
Explanation — autonomy by template spawning

Swarm: the goal agent derives specs, the hive writes its own job descriptions

Transcript (Kimi K2.5, Jan): “There's a goal agent that will help derive some of the goals and specs… You're going to define some subtask or even create some agents with templates by itself… Each little one of these smaller agents are actually created right there instead of defined previously… I don't need to tell it who should be doing what.” The diagram isolates that sentence: Queen → Goal (coral) is the only human-independent derivation. SPAWN ×12 TEMPLATED is not a dispatch of pre-named workers; it is runtime generation. The six boxes on row one and six on row two are shown as separate 112×48 rects because each carries a role description Kimi wrote itself — e.g., “You are a competitive intelligence researcher specializing in AI coding” — not a role you wrote.

Why the box count matters

The transcript calls “100 sub-pages that will work in parallel” as the claim; the observed run spawned 12, 10 succeeded. That gap is intentional to show: swarm scales to the vague intent, not to your org chart. Row one shows the named specialists (AI Coding, Automation, Education/Jane, Lewis) because Kimi surfaced their role strings in the UI. Row two shows Agents 7–11 as generic because the UI scrolled; Agent 12 is coral because it was still completing — 10/12 success is the crowdsource precondition for the synthesizer.

The random-forest analogy — read the right panel first

Sean: “It's kind of like a random forest where you have little sub-trees to make decisions… and then the final layer… cluster the information together.” Each agent is a shallow tree voting on “is this channel relevant to AI devtools/automation/indie?” The Bowen — Clustering Agent (coral synthesizer) is the forest’s final layer: it takes 26 channels from 10 voters, positions them by format, and emits three white-space opportunities (non-dev workflows, rigorous tool comparisons, Spanish gap) — exactly what the transcript credits as “consistent with what Claude told me.”

Choose Swarm when…

  • Intent is vague: “find top 20 YouTellers like Sean’s” without naming lenses
  • You need breadth to de-bias: many parallel opinions, then a clustering vote
  • You accept 2× token cost for autonomous decomposition

Costs and tells

  • Token hunger: 12 agents → more than 5 scouts in Teams — but breadth is the product
  • Polished streaming UI (vs Claw terminal) makes it easier to see who is stuck — Lewis on SaaS solopreneur, Jane on education — without tailing logs
  • Every agent can differ; the synthesizer must reconcile — if it fails, the final clusters inherit the bias

What to steal for your own system

Copy the Goal Agent prompt, not the swarm size. Ask it to emit “specs: top 20, by positioning and format” before it spawns. If the specs are wrong, the swarm will be productively wrong at scale. Fix the specs, not the agents.
