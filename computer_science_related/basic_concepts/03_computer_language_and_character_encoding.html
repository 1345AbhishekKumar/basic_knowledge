Computer Language, Character Encoding & RGB Representation

Discover how computers communicate using the Base-2 binary system, how bits form bytes ($2^8 = 256$ values), how character encodings (ASCII & UTF-8) translate human text, and how the 24-bit RGB model creates millions of colors.

0️⃣1️⃣ 1. The Binary Language (Base-2 Numeral System)

Humans communicate using alphabetical languages (letters forming words, sentences, and paragraphs) and count using the decimal (Base-10) system. Computers, however, operate on a fundamental communication system called the binary system (also known as the base-2 numeral system).

Definition: Binary System

The binary system is a base-2 numeral system that represents values and instructions using only two digits: 0 and 1. A computer computes by comparing billions of 1s and 0s per second.

Why do computers use binary? Because physical electronics are most reliably and efficiently operated in two distinct electrical states:

  • State 1 (High Voltage / ON): Electrical current or voltage is present.
  • State 0 (No Voltage / OFF): Electrical current or voltage is absent.

📦 2. Bits vs. Bytes & The 256 Rule

Bit (Binary Digit)

The smallest atomic unit of digital storage. A bit holds exactly one binary state: either a 0 or a 1.

Byte (8 Bits)

In computing, bits are grouped into bundles of 8 bits. A single byte can store one character of standard text.

Figure 3.1: Structure of 1 Byte (8 bits) containing binary value 01000011 (ASCII 67 = 'C')
The 256 Possibilities Formula

Because each bit has 2 possible states (0 or 1), an 8-bit byte can represent:

28 = 2 × 2 × 2 × 2 × 2 × 2 × 2 × 2 = 256 possible unique values (from 0 to 255)

📖 3. What is Character Encoding?

Definition: Character Encoding

Character encoding is the system used to assign binary values (sequences of 1s and 0s) to human-readable characters (letters, numbers, punctuation, symbols). It functions like a standard dictionary translating machine bits into readable text.

Without character encoding, web pages, emails, and operating systems would display raw, unreadable streams of binary numbers.

🔤 4. The ASCII Standard

The oldest and most foundational character encoding standard is ASCII (American Standard Code for Information Interchange).

  • Uses 7 bits to represent characters.
  • Provides 128 total values (0 to 127) out of the 256 values available in a full byte.
  • Encodes the English alphabet (both UPPERCASE and lowercase), digits 0 through 9, standard punctuation marks, and control characters (like newline and tab).
Character Decimal Value 8-Bit Binary Representation
'A' (Uppercase A) 65 01000001
'a' (Lowercase a) 97 01100001
'B' (Uppercase B) 66 01000010
'0' (Digit zero) 48 00110000
'!' (Exclamation) 33 00100001

🌐 5. Unicode & UTF-8 (Variable-Length Encoding)

While ASCII's 128 characters worked for basic English text, global computing required supporting thousands of non-Latin alphabets (Arabic, Chinese, Cyrillic, Hindi, Japanese, Greek, etc.) plus mathematical symbols and emojis.

Definition: UTF-8 & Unicode

Unicode Standard: A universal character set that defines unique code points for all human languages and symbols.

UTF-8: The most prevalent encoding standard used today. It is backward-compatible with ASCII and uses a variable number of bytes (1 to 4 bytes per character) to represent over a million unique characters and emojis.

Encoding Type Byte Width Supported Range Examples
ASCII Fixed 1 Byte (7 bits used) 128 characters A, b, 7, ?, !
UTF-8 Variable: 1 to 4 Bytes 1,114,112 characters English (1 byte), Spanish/Greek (2 bytes), Asian scripts (3 bytes), Emojis (4 bytes: 😊, 🚀)

🎨 6. Color Representation: The RGB Model

How do computers display millions of vibrant colors on monitor pixels using binary? They use the RGB (Red, Green, Blue) additive color model.

  • A pixel's color is formed by mixing varying intensities of Red, Green, and Blue light.
  • In 24-bit True Color computing, each of the three color channels is allocated 1 byte (8 bits).
  • This yields values ranging from 0 (no intensity) to 255 (maximum intensity) per channel.
  • Total possible colors: $256 \times 256 \times 256 = \mathbf{16,777,216}$ distinct colors.
Color Name Red Channel (0-255) Green Channel (0-255) Blue Channel (0-255) Hex Code
Pure Red 255 0 0 #FF0000
Pure Green 0 255 0 #00FF00
Pure Blue 0 0 255 #0000FF
Pure White 255 255 255 #FFFFFF
Pure Black (Lights Off) 0 0 0 #000000
Yellow 255 255 0 #FFFF00
