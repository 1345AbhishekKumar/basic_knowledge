Explore how microscopic semiconductor transistors form logic gates—the physical building blocks of binary calculation—and how gates combine to create complex calculating circuits.

⚡ 1. What are Logic Gates?

Core Definition: Logic Gates

Logic gates are physical electronic components (constructed from transistors) that specify exact rules for producing an electrical output based on one or more electrical inputs.

Computers represent two binary states: an "ON" (1 / High Voltage) state or an "OFF" (0 / No Voltage) state. A logic gate takes in one or more of these binary signals and determines whether to pass along an "ON" or "OFF" signal.

🚪 2. The Six Essential Logic Gates

Each logic gate is characterized by its schematic symbol, logic rule, and corresponding truth table (which maps all possible input combinations to their resulting output).

1. NOT Gate (Inverter) 1 Input

The simplest gate. Takes 1 input and inverts it to the opposite binary state. If input is 1, output is 0. If input is 0, output is 1.

🔌 3. Combining Gates to Build Circuits

Computers do not use isolated logic gates; they link millions or billions of gates into complex circuits. Gates are chained by feeding the output signal of one gate as the input into another gate.

Circuit Architecture Breakdown

Consider the multi-gate circuit from the curriculum containing an XOR gate, a NOT gate, and an AND gate:

  • Inputs: A and B feed directly into the XOR gate.
  • Output 2: The direct output of the XOR gate: Output 2 = A ⊕ B.
  • Inversion: The XOR output feeds into the NOT gate: NOT(A ⊕ B).
  • Output 1: The AND gate takes original input A and the inverted XOR signal: Output 1 = A AND (NOT(A ⊕ B)).
