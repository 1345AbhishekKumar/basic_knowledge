Master Glossary & Technical Reference

Crisp, authoritative, and exact definitions for all core technical terms covered in Google IT Support: Technical Support Fundamentals.

Abstraction Concepts

To take a relatively complex system and simplify it for our use, hiding unnecessary internal mechanical complexities behind intuitive interfaces.

Algorithm Software

A step-by-step series of instructions or rules designed to solve specific computational or logical problems.

ASCII Encoding

The oldest standard character encoding format. Uses 7 bits to represent 128 characters, including English uppercase/lowercase letters, digits 0-9, and punctuation marks.

Binary System (Base-2) Math & Hardware

The fundamental numerical communication language used by computers, representing all values and instructions using only two digits: 0 and 1.

Bit (Binary Digit) Data

The smallest unit of digital storage in computing, representing a single binary state (either 0 or 1).

Byte Data

A grouped sequence of 8 bits. An 8-bit byte can represent 256 unique values (from 0 to 255) and hold one ASCII character.

Character Encoding Encoding

The standardized dictionary system used to assign binary numerical values to characters (letters, numbers, symbols) so humans can read text.

Compiler Software

Software (first invented by Admiral Grace Hopper) that translates human-readable programming language source code into machine code (zeros and ones).

Computer Hardware

A device that stores and processes data by performing rapid mathematical calculations.

Cryptography Security

The overarching discipline covering the practice and mathematical study of writing and solving secure codes to protect messages from third parties.

Decimal Form (Base-10 System) Math

The standard human counting system based on powers of 10, utilizing 10 possible digits ranging from 0 to 9.

Digital Divide Social Impact

The growing skills and access gap between individuals/communities who have access to modern digital technology and literacy, and those who do not.

Information Technology (IT) Foundations

The use of computers, storage, networking, physical devices, infrastructure, and processes to create, process, store, secure, and exchange all forms of electronic data.

IT/OT Convergence Enterprise & Industry 4.0

The integration of data-centric Information Technology (IT) systems with machine-monitoring Operational Technology (OT) systems across industrial environments.

Linux OS Operating Systems

One of the largest open-source operating systems in the world (created by Linus Torvalds), powering global cloud infrastructure, servers, and Android.

Logic Gates Hardware Logic

Physical electronic components made from transistors that perform binary calculations by producing an electrical output based on specific logical input rules.

Open Source Software

Software development model where copyright holders allow anyone to view, modify, enhance, and distribute the underlying source code for free.

Operational Technology (OT) Hardware

Hardware and software systems that detect or cause changes through direct monitoring and physical control of industrial equipment (SCADA, PLCs, valves, sensors).

PDA (Personal Digital Assistant) Mobile History

Early portable handheld computing devices that brought calendars, contacts, and emails mobile, serving as the direct ancestor to modern smartphones.

Punch Cards History

Stiff paper cards containing sequences of perforated holes used to automatically control looms and store data/instructions for early mechanical and electronic computers.

QWERTY Layout Hardware

The predominant typewriter and computer keyboard layout worldwide, named after the sequence of the first six keys on the top letter row.

RGB Color Model Display

An additive color model where varying intensities of Red, Green, and Blue light are combined (typically 1 byte each, values 0-255) to render 16.7 million colors on screens.

Transistor Hardware

A solid-state semiconductor component that amplifies or switches electrical signals, acting as the microscopic foundation for all modern CPUs and memory chips.

UTF-8 Encoding

The most prevalent variable-width character encoding standard today (using 1 to 4 bytes), built on Unicode to represent all global written languages and emojis.

Vacuum Tube History

An early electronic component used to amplify and switch electricity voltages in early computers like ENIAC; replaced by smaller, cooler transistors.
