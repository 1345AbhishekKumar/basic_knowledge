⚖️ 2. RAM vs. CPU Registers

Feature CPU Registers Random Access Memory (RAM)
Location Inside the CPU die itself. Separate DIMM modules slotted into the motherboard.
Capacity A few bytes (32-bit to 64-bit per register). Gigabytes (8 GB, 16 GB, 32 GB, 64 GB+).
Access Latency Instantaneous (< 1 CPU clock cycle). Multiple clock cycles (requires bus traversal & MCC routing).

Persistence Volatile (lost immediately on CPU cycle or power loss). Volatile (lost when system powers down or reboots).

⚡ 3. DRAM (Dynamic RAM) vs. SRAM (Static RAM)

There are two fundamental semiconductor architectures for RAM:

Dynamic RAM (DRAM)

• Mechanism: Uses 1 transistor and 1 tiny capacitor per bit.

• Refresh Requirement: Capacitors naturally leak charge; DRAM must be refreshed continuously thousands of times per second to prevent data loss.

• Use Case: Main system memory (laptops, desktops, phones). High capacity, low cost.

Static RAM (SRAM)

• Mechanism: Uses flip-flop circuits (4 to 6 transistors per bit).

• No Refreshing: Holds stored data steadily as long as power is supplied without needing refresh cycles.

• Use Case: CPU L1/L2/L3 cache memory. Ultra-fast and reliable, but expensive and physically larger.

📊 4. DDR SDRAM Generations & DIMM Form Factors

Modern RAM is SDRAM (Synchronous DRAM), synchronized with the CPU system clock. The prevailing technology is DDR (Double Data Rate) SDRAM, which transmits data on both the rising and falling edges of the clock signal, doubling data throughput.

Generation Key Enhancements Operating Voltage Physical Form Factor
DDR1 First double data rate standard (200-400 MT/s). 2.5 V 184-pin DIMM
DDR2 Improved bus speeds and lower power consumption. 1.8 V 240-pin DIMM
DDR3 Doubled prefetch buffer, higher clock speeds. 1.5 V 240-pin DIMM (different notch)
DDR4 Higher density, improved error detection, high bandwidth. 1.2 V 288-pin DIMM
DDR5 Dual-channel per DIMM, on-die ECC, extreme frequencies (4800+ MT/s). 1.1 V 288-pin DIMM (centered notch)
DIMM Sticks & Motherboard Compatibility

DIMM (Dual Inline Memory Module): The standard form factor circuit board for desktop RAM. Each DDR generation features a physical alignment notch placed in a different position along the connector pins to mechanically prevent inserting incompatible RAM generations into the motherboard.

📑 5. Virtual Memory (Paging)

When you open dozens of browser tabs and applications that exceed your physical RAM capacity (e.g., trying to use 18 GB of memory on a 16 GB system), the operating system prevents system crashes using Virtual Memory:

How Virtual Memory Works

The OS creates a dedicated paging file (e.g., pagefile.sys in Windows or a swap partition in Linux) on secondary storage (SSD/HDD). Inactive memory blocks ("pages") are swapped out of RAM onto disk to free physical RAM for the active foreground application.

Note: Because secondary storage is slower than physical RAM, excessive swapping causes performance slowdowns known as thrashing.

🔒 6. Read-Only Memory (ROM) & Types

Unlike volatile RAM, Read-Only Memory (ROM) is non-volatile; it stores permanent startup code (bootstrap loader) that launches the operating system:

1. PROM

Programmable ROM: Manufactured blank and written once using a high-voltage PROM programmer. Permanent; cannot be erased or modified.

2. EPROM

Erasable Programmable ROM: Can be erased by removing the chip and exposing its quartz window to intense ultraviolet (UV) light for 20-30 minutes, then reprogrammed.

3. EEPROM (Flash ROM)

Electrically Erasable PROM: Can be erased and rewritten electrically in circuit without removing the chip. Used for modern motherboard BIOS/UEFI firmware updates.
