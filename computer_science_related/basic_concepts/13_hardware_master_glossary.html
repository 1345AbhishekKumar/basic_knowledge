Hardware Master Glossary & Quick Reference

Comprehensive, searchable terminology definitions for computer hardware, processor internals, memory busses, motherboard form factors, and mobile systems.

Address Bus CPU Architecture

A dedicated set of bus lines connecting the CPU directly to the Memory Controller Chip (MCC) that sends over the exact location/address of the requested data in RAM, but not the data itself.

ATA / SATA Storage

Advanced Technology Attachment / Serial ATA. The most common interface and protocol for connecting internal hard disk drives and solid-state drives using thin serial data cables.

ATX (Advanced Technology Extended) Motherboard

The industry-standard motherboard form factor (12 × 9.6 inches) used in full-sized desktop computers and workstations, providing up to 7 expansion slots.

Backward Compatible Hardware Standards

The ability of newer hardware standards or ports (such as USB 3.0 or PCIe Gen 4) to successfully communicate and interoperate with legacy hardware devices.

BIOS (Basic Input/Output System) Firmware

Low-level firmware stored in non-volatile ROM on the motherboard that initializes hardware components, runs POST diagnostics, and hands control to the OS bootloader.

BYOD (Bring Your Own Device) Enterprise IT

An organizational policy allowing employees to use their personal smartphones, tablets, and laptops for corporate work while maintaining security sandboxes and privacy compliance.

Cache (CPU) Memory

Ultra-fast Static RAM (SRAM) integrated into the CPU die that stores frequently accessed instructions and data to minimize access latency from system RAM (L1, L2, L3 levels).

Charge Cycle Batteries

One complete discharge of 100% of a rechargeable battery's total capacity followed by a full 100% recharge, used as the primary metric for battery degradation and lifespan.

Chipset Motherboard

The set of integrated circuits on a motherboard (historically Northbridge and Southbridge; modern Platform Controller Hub) that manages and coordinates data communication between CPU, RAM, and peripherals.

Clock Cycle & Clock Speed CPU Architecture

A clock cycle is one pulse of work performed by the CPU. Clock speed is the frequency of cycles per second, measured in Gigahertz (GHz, billions of cycles/sec).

CMOS RAM & Battery Motherboard

Low-power volatile memory on the motherboard storing BIOS configuration and real-time clock data, kept energized when wall power is disconnected by a coin-cell CMOS battery.

CPU (Central Processing Unit) Processors

The primary computing engine of the system responsible for executing instructions and performing calculations via its Arithmetic Logic Unit (ALU), Control Unit (CU), and Registers.

CPU Sockets (LGA vs. PGA) Hardware

Motherboard connectors for processors. LGA (Land Grid Array) has pins on the socket; PGA (Pin Grid Array) has pins on the CPU itself.

DDR SDRAM Memory

Double Data Rate Synchronous DRAM; transfers data on both the rising and falling edges of the clock cycle, doubling memory bandwidth (DDR1 through DDR5).

DIMM (Dual Inline Memory Module) Memory

The standard physical circuit board form factor for desktop RAM modules, featuring keyed notches to prevent installing incompatible DDR generations.

DRAM vs. SRAM Memory

DRAM (Dynamic RAM) uses 1 transistor + 1 capacitor per bit and requires constant refresh cycles (system RAM). SRAM (Static RAM) uses flip-flops and holds charge without refresh (CPU cache).

Electrostatic Discharge (ESD) Safety

The sudden flow of static electric current between objects caused by contact; mitigated during computer assembly by wearing grounded anti-static wristbands.

External Data Bus (EDB) Busses

A physical collection of parallel traces connecting the CPU, memory, and motherboard components that transports raw binary data in 8-bit to 64-bit widths.

Form Factor Hardware

The standardized physical size, shape, mounting screw hole positions, and layout specifications of motherboards, power supplies, and storage chassis.

HDD (Hard Disk Drive) Storage

Non-volatile mechanical storage device using rapidly spinning magnetic platters and moving actuator arms to read and write persistent data.

Heat Sink & Thermal Paste Cooling

A metal finned passive cooler that dissipates CPU thermal energy. Thermal paste fills microscopic surface air pockets to maximize thermal conduction between CPU and heat sink.

ITX (Information Technology Extended) Motherboard

A family of ultra-compact motherboard form factors (Mini-ITX, Nano-ITX, Pico-ITX) engineered for small form factor (SFF) cubes, home theaters, and embedded hardware.

Memory Controller Chip (MCC) CPU Architecture

The hardware controller bridge that retrieves requested data rows from system RAM based on address bus queries and places the bytes onto the External Data Bus (EDB).

Motherboard Hardware

The primary printed circuit board ("circulatory system") of the computer that physically holds components and routes all electrical power and data buses.

Northbridge & Southbridge Chipset

Legacy two-chip chipset architecture. Northbridge handled high-speed RAM and graphics; Southbridge managed lower-speed storage and I/O (SATA, USB, audio).

NVMe (Non-Volatile Memory Express) Storage

A modern high-speed storage protocol engineered specifically for SSDs that operates over the PCIe bus, providing ultra-low latency and deep parallel command queues.

Overclocking Processors

The practice of increasing a CPU's clock multiplier, base frequency, or voltage beyond factory default specifications to achieve higher computing performance.

PCI Express (PCIe) Expansion

The primary high-speed serial expansion bus standard on modern motherboards used to seat dedicated GPUs, NVMe SSDs, and high-speed network interface cards (NICs).

Peripherals & Ports Hardware

Ports are physical connection interfaces on a computer. Peripherals are external hardware devices (keyboards, mice, monitors, printers) connected via ports to extend functionality.

Platform Controller Hub (PCH) Chipset

Modern single-chip architecture that replaced the traditional Northbridge/Southbridge pair after high-speed memory controllers were integrated directly onto the CPU die.

POST (Power-On Self-Test) Firmware

The initial automated diagnostic test executed by BIOS/UEFI on cold boot to verify operational integrity of the CPU, memory, GPU, and controllers before booting the OS.

Power Supply Unit (PSU) Power

Hardware component that converts high-voltage Alternating Current (AC) from the wall into regulated low-voltage Direct Current (DC) rails (+12V, +5V, +3.3V) for PC hardware.

RAM (Random Access Memory) Memory

Fast volatile system memory used by the operating system to store active application code and working data for direct high-speed execution by the CPU.

Registers (CPU) CPU Architecture

Microscopic, ultra-fast memory storage cells built directly into the processor die that hold immediate instruction operands, memory pointers, and calculation results.

Reimaging & Disk Image Deployment

A disk image is an exact sector-by-sector clone of an operating system. Reimaging is the automated process of wiping a storage drive and restoring a pristine disk image.

Return Merchandise Authorization (RMA) IT Support

A structured warranty process authorizing the return of defective hardware to the original equipment manufacturer (OEM) for certified repair, refund, or replacement.

ROM (Read-Only Memory) Memory

Non-volatile memory that retains stored bootstrap instructions even without electrical power (variants include PROM, UV-erasable EPROM, and modern Flash EEPROM).

SoC (System On a Chip) Mobile

An integrated circuit die that bundles the CPU, GPU, memory, cellular modem, and I/O controller into a single compact silicon package for mobile devices.

SSD (Solid State Drive) Storage

High-speed, non-volatile persistent storage device utilizing semiconductor NAND flash memory chips with zero moving parts, providing silent and shock-resistant operation.

Standoffs Motherboard

Brass or metal mounting spacers screwed into the computer case beneath the motherboard to prevent metal-on-metal electrical short circuits.

UEFI (Unified Extensible Firmware Interface) Firmware

The modern 32/64-bit firmware specification replacing legacy BIOS, offering Graphical User Interfaces (GUIs), mouse support, Secure Boot, and GPT partition drive support.

USB-C Connectors

A 24-pin reversible physical connector standard supporting high data bandwidth (up to 20/40 Gbps), DisplayPort video, and up to 240W Power Delivery (USB-PD).

Virtual Memory (Paging) Memory

An OS memory management feature that reserves space on secondary storage (swap/pagefile) to temporarily hold inactive memory pages when physical RAM is exhausted.
