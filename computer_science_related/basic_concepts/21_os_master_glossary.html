Operating Systems Master Glossary & Quick Reference

Searchable reference defining core concepts in operating systems, kernel functions, process scheduling, file system architectures, and remote access protocols.

Android Mobile OS

A mobile operating system built on top of the open-source Linux kernel, widely deployed across smartphones, tablets, and smart devices worldwide.

Application Software

A computer program designed in user space to perform specific tasks for end-users, such as word processing, web browsing, or media editing.

BIOS / UEFI Firmware

Low-level software stored on motherboard ROM that initializes physical computer hardware during startup and executes the POST diagnostics before loading the OS.

BitLocker Security

A full-volume drive encryption tool integrated into Windows Pro and Enterprise editions that protects data from unauthorized access when a computer is stolen or offline.

Block Storage Storage

A storage architecture where file data is partitioned into discrete uniform chunks (blocks) and distributed non-contiguously across storage sectors, improving access speeds and space allocation.

Boot System Startup

The initialization process of starting a computer and loading the operating system kernel into memory from an unpowered state.

Bootloader System Startup

A small program (such as GRUB or Windows Boot Manager) located in the drive's boot sector that loads the operating system kernel from storage into physical RAM.

Chrome OS Operating Systems

A lightweight, cloud-centric operating system developed by Google based on the Linux kernel, centered around the Google Chrome web browser and cloud services.

Command Line Interface (CLI) User Space

A text-based user interface and shell where users enter structured text commands to interact with the operating system, run scripts, and manage system resources.

Computer File File Systems

A discrete digital resource on a storage device containing raw data (documents, images, audio, executable binaries) managed by the OS file system.

Data Blocks File Systems

Fixed-size storage units (commonly 4 KB clusters) on a disk where parts of a file are written by the file system.

Distributions (Linux Distros) Linux

Complete operating systems built around the Linux kernel bundled with package managers, system utilities, and desktop environments (e.g. Ubuntu, Debian, Red Hat).

Etcher.io Tools

A popular cross-platform utility used to burn OS installation images (.iso) onto USB flash drives to make them bootable from BIOS/UEFI.

File Extension File Systems

A suffix appended to a filename (e.g. .docx, .jpg, .exe) that specifies the file type and indicates to the OS which default program should open it.

File System File Systems

The overall organizational framework, directory hierarchy, and database that manages how files are named, indexed, stored, and retrieved on secondary storage (NTFS, ext4, APFS).

Finder macOS

The default visual file manager and graphical desktop interface for all Apple macOS computers.

Folders / Directories File Systems

Virtual containers used by the file system to organize files hierarchically into logical folders and subdirectories.

Hardware Resource Deficiency Troubleshooting

A bottleneck where a computer's physical resources (CPU, RAM, or Disk I/O) are fully exhausted, causing system latency and slow response times.

HFS+ / APFS File Systems

Apple file systems. HFS+ is the legacy journaling system; APFS is the modern 64-bit encrypted, crash-resistant file system standard across all Apple devices.

Hostname Networking

A unique alphanumeric human-readable label assigned to a computer to identify it across local networks and internet protocols.

I/O Management Kernel Functions

The kernel subsystem that manages communication between the operating system and input/output hardware devices via device drivers.

iOS Mobile OS

Apple's proprietary mobile operating system engineered for iPhone and iPad devices, emphasizing sandboxed security, touch gesture UX, and power efficiency.

Kernel Core OS

The fundamental supervisor core of an operating system executing in Ring 0 with full hardware control, managing file storage, CPU process scheduling, memory, and I/O devices.

Logs Troubleshooting

Chronological system files that record operational events, software errors, login authentications, and hardware status on a computer.

macOS Operating Systems

Apple's Unix-based desktop operating system pre-loaded on Mac computers, featuring tight integration with the Apple hardware ecosystem.

Memory Management Kernel Functions

A core kernel function that optimizes physical RAM allocation, isolates memory spaces between processes, and manages virtual memory swapping.

Metadata File Systems

Structured descriptors providing essential context about a file (creator, modified timestamp, access permissions, file size, and extension).

Microsoft Terminal Services Client (MSTSC) Remote Access

The built-in Windows client application used to initiate Remote Desktop Protocol (RDP) connections to remote workstations and servers.

OpenSSH Remote Access

The premier open-source suite of secure network connectivity tools implementing the SSH protocol for encrypted terminal management.

Operating System (OS) Core OS

The comprehensive system software package that manages physical hardware, executes application processes, enforces security, and provides user interfaces.

Plink (PuTTY Link) Remote Access

A command-line interface tool included with the PuTTY suite used to automate remote SSH sessions from command scripts.

PowerShell User Space

An advanced object-oriented command shell and scripting language developed by Microsoft for task automation and system configuration.

Power User IT Concepts

An advanced computer user or IT specialist who utilizes command shells, custom scripts, and direct system configurations to maximize productivity.

Process Management Kernel Functions

Kernel capacity to schedule CPU execution order, assign time slices, manage resource allocation, and terminate executing software processes.

Process vs. Program Process Management

A program is passive code on disk; a process is an active executing instance loaded into RAM with an assigned PID and CPU time.

Remote Desktop Protocol (RDP) Remote Access

Microsoft network protocol (Port 3389) providing remote graphical desktop access to Windows workstations and servers.

Scalability Infrastructure

The ability of a system or network architecture to dynamically increase or decrease its performance capacity and resources in response to changing workload demands.

Shell User Space

A user space interpreter program (Bash, PowerShell) that translates text commands into system calls executed by the operating system kernel.

SSH (Secure Shell) Remote Access

An encrypted cryptographic protocol (Port 22) allowing administrators to securely access and manage remote command-line terminal sessions.

Swap Space (Pagefile) Memory

Reserved secondary storage space used by virtual memory to store temporarily swapped-out pages when physical RAM is full.

Taskbar User Space

A persistent desktop GUI element providing quick access to running applications, start menus, notifications, network connectivity, and the system clock.

Terminal User Space

A text-based software interface and window used to type commands into the shell interpreter.

Time Slice (Quantum) Process Management

A microscopic duration of CPU execution time allocated to a process by the kernel process scheduler before context switching.

Ubuntu Linux

A leading Debian-based Linux distribution renowned for its user-friendly desktop experience, cloud server dominance, and 2-year Long-Term Support (LTS) release cycle.

User Space Core OS

The unprivileged Ring 3 operating system layer where users interact directly with graphical desktop environments, web browsers, media players, and shells.

Virtual Machine (VM) Virtualization

A complete software emulation of physical computer hardware that enables running multiple isolated guest operating systems concurrently on a single host machine.

Virtual Memory Memory

A memory management technique that combines physical RAM with secondary storage swap space, allowing large applications to run without running out of memory.

Virtual Private Network (VPN) Remote Access

An encrypted network tunnel connecting a remote client securely to a private corporate Local Area Network (LAN) across the public internet.
