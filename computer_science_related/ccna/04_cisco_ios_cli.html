Lesson 04: Cisco IOS CLI & Device Admin

Comprehensive guide to Cisco Internetwork Operating System (IOS) navigation, command mode hierarchy (User EXEC, Privileged EXEC, Global Config), RAM vs NVRAM management, Type 5 vs Type 7 password encryption, and terminal configuration.

🖥️ 1. Out-of-Band Console Access (Rollover & USB)

Initial configuration of a brand-new Cisco switch or router requires an out-of-band management connection using the dedicated physical Console Port:

RJ45 Rollover Console Cable

A flat light-blue cable with an RJ45 connector on one end and a DB9 / USB serial adapter on the workstation end. Pin 1 connects to Pin 8, Pin 2 to Pin 7 ("rolled" pinout).

Mini-USB / Type-C Console

Modern Cisco devices feature direct USB console ports requiring a standard USB cable and Cisco USB Console driver installed on the administrative laptop.

⚙️ Standard PuTTY / Terminal Emulator Settings

Speed (Baud Rate): 9600 bps | Data Bits: 8 | Parity: None | Stop Bits: 1 | Flow Control: None (Rule: 9600-8-N-1).

🪜 2. Cisco IOS Command Mode Hierarchy

Cisco IOS utilizes a strict hierarchical mode structure to safeguard against unintended configuration changes:

Command Mode CLI Prompt How to Enter Mode How to Exit Mode Permitted Actions & Scope
User EXEC Mode Router> Default upon initial console connection or SSH login. exit or logout View-only basic diagnostics (ping, traceroute, limited show commands). Cannot modify device state.
Privileged EXEC Mode (Enable Mode) Router# Router> enable disable (returns to >) or exit Full administrative control. Execute detailed show running-config, debugs, file management, reload device.
Global Configuration Mode Router(config)# Router# configure terminal (shortcut: conf t) exit (returns to #) or end / Ctrl+Z Apply device-wide configuration commands (hostname, banners, static routes, enable passwords).
Interface Config Mode Router(config-if)# Router(config)# interface gigabitethernet 0/0 exit (returns to (config)#) Configure specific port IP addresses, duplex, speed, and no shutdown.
Line Config Mode Router(config-line)# Router(config)# line console 0 or line vty 0 4 exit Configure management access authentication for Console and Telnet/SSH VTY lines.

⌨️ 3. CLI Navigation Shortcuts & Error Handling

Productivity Shortcuts

  • Tab: Auto-completes a partially typed unique command.
  • ?: Context-sensitive help (lists commands or arguments).
  • Ctrl+A: Jump cursor to beginning of the line.
  • Ctrl+E: Jump cursor to end of the line.
  • Ctrl+Z: Instantly exit any sub-mode to Privileged EXEC (#).
  • Ctrl+Shift+6: Abort running DNS lookup or continuous ping.

Cisco IOS CLI Syntax Errors

  • % Ambiguous command: Not enough characters provided to distinguish between multiple matching commands (e.g. c matches clock, clear, configure).
  • % Incomplete command: The command is valid but required trailing parameters were omitted.
  • % Invalid input detected at '^' marker: Typo or syntax error at the exact position indicated by the caret (^).

💾 4. Memory Architecture (RAM vs NVRAM)

Cisco hardware operates with distinct physical memory tiers:

Memory Component Volatility Config File Stored Behavior & Administration
RAM (Random Access Memory) Volatile (Lost on reboot) running-config Holds the active running configuration, routing tables, ARP cache, and packet buffers. Changes made in CLI take effect immediately here.
NVRAM (Non-Volatile RAM) Non-Volatile (Permanent) startup-config Holds the saved startup configuration loaded by the device when powered on.
Flash Memory Non-Volatile Cisco IOS Image (.bin) Solid-state storage holding operating system software images.
ROM (Read-Only Memory) Non-Volatile Read-Only Bootstrap & ROMMON Hardware firmware executing power-on self-test (POST) and disaster recovery.
💾 Saving the Configuration

To commit your active changes from volatile RAM into non-volatile NVRAM, execute:
Router# copy running-config startup-config (shortcut: copy run start)
or the legacy command: Router# write memory (shortcut: wr).

🔒 5. Password Security: `enable secret` vs `enable password`

Protecting access to Privileged EXEC mode is critical. Cisco IOS supports two primary commands:

Feature enable password <pwd> enable secret <pwd>
Encryption Strength Plaintext (Type 0) or Weak Vigenère Cipher (Type 7) Type 5 MD5 Hash (starts with $1$) or Type 8/9 SHA-256
Reversibility Easily decrypted with online Type 7 tools One-way mathematical cryptographic hash (irreversible)
Precedence Rule Ignored if enable secret is set ALWAYS takes precedence over enable password
⚠️ Service Password-Encryption

Executing Router(config)# service password-encryption converts plaintext passwords into Type 7 reversible hashes to prevent "shoulder surfing". However, for the enable password, always use enable secret for robust cryptographic security.

📝 7. CCNA 200-301 Official Quiz & Knowledge Check

1. Which command mode is indicated by the prompt `Router(config)#`?
A. User EXEC mode
B. Privileged EXEC mode
C. Global configuration mode (Correct)
D. Interface configuration mode
Explanation: The prompt Router(config)# represents Global Configuration Mode, where device-wide settings are applied.
2. If both `enable password cisco` and `enable secret ccna` are configured on a router, which password must you enter to access Privileged EXEC mode?
A. cisco
B. ccna (Correct)
C. Both passwords in sequence
D. Neither (the router locks out)
Explanation: enable secret ALWAYS supersedes enable password due to its cryptographic MD5/SHA hash security. The password is ccna.
3. Where is the active `running-config` file stored on a Cisco switch?
A. In volatile RAM (Correct)
B. In non-volatile NVRAM
C. In Flash memory
D. In ROM
Explanation: The running-config resides in RAM and is lost on reboot unless saved to NVRAM as the startup-config.
4. Which keystroke instantly takes you from `Router(config-if)#` back to Privileged EXEC `Router#`?
A. Ctrl+C only
B. Tab
C. Ctrl+Z or typing end (Correct)
D. Ctrl+Shift+6
Explanation: Ctrl+Z or the command end immediately breaks out of any configuration sub-mode back to Privileged EXEC (#).
5. What error message does Cisco IOS display if you type an incomplete command lacking required parameters?
A. % Ambiguous command
B. % Incomplete command (Correct)
C. % Invalid input detected at '^' marker
D. % Bad argument
Explanation: When a command keyword is recognized but required parameters are missing, IOS outputs % Incomplete command.
