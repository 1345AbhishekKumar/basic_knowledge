Lesson 05: Ethernet Switching, MAC & ARP

Master IEEE 802.3 Ethernet frame anatomy (18-byte overhead, padding zeroes, minimum 64-byte frame size), 48-bit MAC address OUI architecture, switch learning and forwarding CAM logic, flooding rules, ARP resolution, and ICMP Ping mechanics.

📦 1. IEEE 802.3 Ethernet Frame Anatomy

The Ethernet Frame is the standardized Layer 2 Data Link PDU. The Ethernet header (14 bytes) and trailer (4-byte FCS) create exactly 18 bytes of protocol overhead:

Preamble 7 Bytes (56b)
SFD 1 Byte (8b)
Dest MAC 6 Bytes (48b)
Source MAC 6 Bytes (48b)
Type / Len 2 Bytes (16b)
Payload + Padding 46 to 1500 Bytes
FCS / CRC 4 Bytes (32b)
Field Name Length Technical Purpose & RFC Specifications
Preamble 7 Bytes (56 bits) Alternating bit pattern (10101010 10101010...) allowing the receiving NIC to synchronize its internal clock frequency.
SFD (Start Frame Delimiter) 1 Byte (8 bits) Pattern 10101011 signaling the exact boundary where the frame header begins.
Destination MAC Address 6 Bytes (48 bits) Physical Layer 2 address of the next-hop receiver or destination device.
Source MAC Address 6 Bytes (48 bits) Physical Layer 2 address of the transmitting node's NIC.
Type (EtherType) 2 Bytes (16 bits) Identifies the encapsulated Layer 3 protocol (0x0800 = IPv4, 0x86DD = IPv6, 0x0806 = ARP).
Data Payload & Padding 46 – 1500 Bytes The encapsulated network packet. Minimum payload is 46 bytes. If the payload is smaller (e.g., a 36-byte ping), padding zeroes are added so the frame meets the mandatory 64-byte minimum size ($6+6+2+46+4 = 64$ bytes). Standard max MTU is 1500 bytes ($1500+18=1518$ bytes).
FCS (Frame Check Sequence) 4 Bytes (32 bits) A 32-bit CRC polynomial calculated by the sender and re-calculated by the receiver. Corrupted frames are discarded (error recovery occurs at Layer 4 TCP).

🏷️ 2. MAC Addressing & OUI Architecture

A MAC (Media Access Control) address is a 48-bit (6-byte) physical identifier permanently burned into the ROM of every Network Interface Card (NIC):

MAC Address Formatting Standards

• Cisco IOS Format: e8ba.7011.2874 (3 groups of 4 hex digits)
• Windows Format: E8-BA-70-11-28-74 (hyphen separated)
• Linux / IEEE Standard: e8:ba:70:11:28:74 (colon separated)

OUI vs Vendor Device ID

• OUI (Organizationally Unique Identifier): First 24 bits (E8BA.70) assigned by IEEE to the vendor (Cisco, Apple, Intel).
• Device Identifier / BIA (Burned-In Address): Last 24 bits (11.2874) uniquely assigned by the manufacturer.

💡 Unicast vs Multicast vs Broadcast MAC

• Unicast MAC: Targets a single unique device.
• Multicast MAC: Targets a subscriber group (IPv4 multicasts map to 01-00-5E-xx-xx-xx).
• Broadcast MAC: FFFF.FFFF.FFFF (all 48 bits set to 1) targeting all devices in the broadcast domain.

⚙️ 3. Switch Forwarding Logic & MAC Address Table (CAM)

When an Ethernet frame enters a switch interface, the switch executes a two-step algorithmic logic:

Step 1: Learning (Source MAC Inspection)

The switch reads the Source MAC address of the incoming frame. It enters the Source MAC, ingress port, and VLAN into its MAC Address Table (CAM Table) and resets the 5-minute (300-second) aging timer.

Step 2: Forwarding Decision (Destination MAC Lookup)

The switch checks its MAC table for the Destination MAC:

  • Known Unicast: Forward out of the matching egress port only (filtered on all others).
  • Unknown Unicast: Flood out of all ports except the ingress port.
  • Broadcast (FFFF.FFFF.FFFF): Flood out of all ports except the ingress port.

⏳ 4. MAC Aging Timer & Cisco IOS Management Commands

Dynamic MAC entries are purged from the switch's CAM table after 300 seconds (5 minutes) of inactivity:

Cisco IOS Command Operational Function
Switch# show mac address-table Displays the active MAC address table (VLAN, MAC, Type DYNAMIC/STATIC, Port).
Switch# clear mac address-table dynamic Flushes all dynamically learned MAC address table entries from memory.
Switch# clear mac address-table dynamic interface Fa0/1 Clears dynamic MAC table entries associated with a specific interface.

🔍 5. Address Resolution Protocol (ARP)

Within a local IP subnet, a host knows the destination IP address but requires the destination Layer 2 MAC address to encapsulate the frame onto the physical wire. ARP resolves IPv4 addresses (Layer 3) to MAC addresses (Layer 2):

ARP Phase Transmission Type Destination MAC Payload Content
ARP Request Broadcast (flooded across LAN) FFFF.FFFF.FFFF "Who has IP 192.168.1.20? Tell 192.168.1.10"
ARP Reply Unicast (point-to-point) 0000.0C11.1111 (Requester's MAC) "192.168.1.20 is at MAC 0000.0C22.2222"
📋 Viewing the ARP Cache

• Windows / Linux: arp -a (displays IP-to-MAC resolution table)
• Cisco IOS: Router# show ip arp

📡 6. ICMP Protocol & The 7 Uses of Ping

The Ping diagnostic utility relies on ICMP (Internet Control Message Protocol - Protocol 1) Echo Requests (Type 8) and Echo Replies (Type 0):

The 7 Primary Uses of Ping

  • 1. Basic IP reachability and connectivity testing.
  • 2. Measuring round-trip time (RTT latency).
  • 3. Packet loss detection over distance.
  • 4. Testing DNS hostname resolution.
  • 5. Verifying firewall and ACL security rules.
  • 6. Monitoring network stability over time.
  • 7. Validating MTU and fragmentation behavior.

Why the First Cisco Ping Drops (.!...)?

When pinging an uncontacted host on a Cisco router, the output is frequently .!... (80% success). The first ICMP packet is placed in a hold buffer while the router generates an ARP Request. If the ARP resolution takes longer than the ICMP buffer timer, the first packet is dropped while subsequent packets succeed!

📝 8. CCNA 200-301 Official Quiz & Knowledge Check

1. Which field of an Ethernet frame provides receiver clock synchronization?
A. Preamble (Correct)
B. Start Frame Delimiter (SFD)
C. Type / Length
D. Frame Check Sequence (FCS)
Explanation: The 7-byte Preamble contains 56 alternating bits (10101010...) that enable the receiving NIC to synchronize its clock timing before decoding data.
2. How long is the physical (MAC) address of a network interface card?
A. 32 bytes
B. 32 bits
C. 48 bytes
D. 48 bits (Correct)
Explanation: A MAC address is exactly 48 bits (6 bytes) in length, written in hexadecimal notation.
3. What is the OUI of the MAC address: E8BA.7011.2874?
A. E8BA
B. E8BA.70 (Correct)
C. 7011.2874
D. 11.2874
Explanation: The OUI (Organizationally Unique Identifier) comprises the first 24 bits (3 bytes), which corresponds to E8BA.70.
4. Which field of an Ethernet frame does a switch inspect to populate its MAC address table?
A. Destination MAC Address
B. Source MAC Address (Correct)
C. Type / Length
D. FCS Checksum
Explanation: Switches learn dynamically by inspecting the Source MAC Address of received frames, associating it with the ingress port.
5. What kind of frames does a switch flood out of all interfaces except the one it was received on?
A. Broadcast and Unknown Unicast (Correct)
B. Known Unicast only
C. Corrupt frames
D. Known Unicast and Multicast
Explanation: Switches flood Broadcast frames (FFFF.FFFF.FFFF) and Unknown Unicast frames (frames whose destination MAC is not yet recorded in the MAC table).
