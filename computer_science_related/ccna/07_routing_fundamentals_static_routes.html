Lesson 07: Routing Fundamentals & Static Routes

Comprehensive mastery of Cisco Layer 3 routing mechanics, routing table architecture (show ip route), Connected vs Local /32 routes, the Longest Prefix Match rule, Default Routes, the 3 fundamental routing table principles, and static route summarization.

🧭 1. Routing Fundamentals & Packet Forwarding Engine

Routing is the process routers use to inspect the Layer 3 destination IP of incoming packets, look up the best matching route in their Routing Table, rewrite the Layer 2 framing headers, and forward the packet toward the next-hop router or destination host.

🚨 Crucial CCNA Rule: Routers NEVER Flood Unknown Packets

Unlike switches that flood unknown unicast frames out of all ports, routers NEVER flood packets. If a router receives a packet whose destination IP does not match ANY route in its routing table (and no default route exists), the router immediately DROPS the packet and discards it!

Layer 2 Frame Rewriting

At every router hop, the old Layer 2 Ethernet header and trailer are stripped. The router decrements the TTL, recalculates the IP checksum, and encapsulates the packet into a brand new Layer 2 frame with the next-hop MAC address. Source and Destination IP addresses stay constant end-to-end.

Static vs Dynamic Routing

Static Routing: Manually configured by an administrator. Highly secure and deterministic with zero CPU/bandwidth overhead, but unscalable in large dynamic networks.
Dynamic Routing: Protocols (OSPF, EIGRP, BGP) share topology updates automatically and reroute around link failures.

📍 3. Connected (`C`) vs Local (`L` /32) Routes

When you configure ip address 192.168.1.1 255.255.255.0 on GigabitEthernet0/0 and execute no shutdown, Cisco IOS automatically injects TWO entries into the routing table:

Connected Route: C 192.168.1.0/24

Represents the entire network subnet attached to the interface. Used to forward outbound packets to destination hosts residing in that subnet (e.g., 192.168.1.10, 192.168.1.50).

Local Route: L 192.168.1.1/32

Has a strict /32 host prefix covering only the exact IP address assigned to the router interface. Packets matching this route are received and processed by the router itself (SSH, Telnet, SNMP, Ping, routing updates).

🎯 4. The Longest Prefix Match Rule

When a router receives a packet, the destination IP address might match multiple routes in the routing table. The router ALWAYS selects the matching route with the longest prefix length (most specific mask):

Routing Table Entry Prefix Length Specificity Rank Matched Destinations
L 10.0.1.23/32 /32 (32 bits) 1st (Most Specific) Matches only 10.0.1.23 (Router self-delivery)
C 10.0.1.0/24 /24 (24 bits) 2nd Matches 10.0.1.1 – 10.0.1.254
S 10.0.0.0/16 /16 (16 bits) 3rd Matches 10.0.0.1 – 10.0.255.254
S* 0.0.0.0/0 /0 (0 bits) 4th (Least Specific) Matches ALL destination IPs (Default catch-all)

🚪 5. Default Gateways & Default Static Routes (`0.0.0.0/0`)

End hosts (such as PCs and servers) do not maintain full Internet routing tables. When PC1 needs to transmit to an IP outside its local subnet (e.g. 192.168.4.10 or 8.8.8.8), it sends the frame to its configured Default Gateway (the local router interface IP) by resolving the router's MAC address via ARP.

💡 Default Static Route Syntax (Gateway of Last Resort)

A default static route matches every packet that has no specific routing table entry. In Cisco IOS, the netmask must be written out in dotted-decimal format (0.0.0.0 0.0.0.0):
Router(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.2
or using exit interface:
Router(config)# ip route 0.0.0.0 0.0.0.0 GigabitEthernet0/2

📜 6. The 3 Routing Table Principles (Alex Zinin)

Principle 1: Independent Local Decision-Making

Every router makes its forwarding decision based exclusively on the contents of its own routing table. A router never queries or inspects the routing tables of neighboring routers during packet transit.

Principle 2: Routing Isolation

The fact that Router A knows a route to a remote destination does NOT mean that downstream Router B or Router C has that same route. As network engineers, we must ensure all routers in the forwarding path possess complete routing knowledge.

Principle 3: Asymmetric Return Paths

Having a valid route to forward packets to a destination does NOT guarantee that return packets will come back! Network communication is bidirectional (e.g. Ping Echo Request requires Echo Reply). Return routes must be explicitly configured on all remote routers.

🛠️ 7. Static Route Configuration in Cisco IOS

The standard syntax for configuring a static route in Global Configuration Mode is:

Router(config)# ip route <destination-network> <subnet-mask> <next-hop-ip | exit-interface>
Method Example Command Lookup Mechanics & Trade-offs
Next-Hop IP ip route 192.168.4.0 255.255.255.0 192.168.12.2 Requires a Recursive Route Lookup on Ethernet to resolve the egress interface.
Exit Interface ip route 192.168.4.0 255.255.255.0 GigabitEthernet0/1 Directly forwards out of the interface (best for Point-to-Point serial/tunnels).
Fully Specified ip route 192.168.4.0 255.255.255.0 g0/1 192.168.12.2 Combines exit interface and next-hop IP for optimal multi-access performance.

📦 8. Route Summarization

When a router connects multiple contiguous LAN subnets, an engineer can summarize them into a single aggregate static route to reduce routing table size and CPU overhead:

Subnet 1st & 2nd Octets 3rd Octet (Binary Breakdown) 4th Octet
192.168.1.0/24192.168.0 0 0 0 0 0 0 1.0
192.168.2.0/24192.168.0 0 0 0 0 0 1 0.0
192.168.3.0/24192.168.0 0 0 0 0 0 1 1.0
192.168.4.0/24192.168.0 0 0 0 0 1 0 0.0
192.168.5.0/24192.168.0 0 0 0 0 1 0 1.0

Resulting Summary Route: Matching the first 21 bits yields 192.168.0.0/21 with subnet mask 255.255.248.0:
Router(config)# ip route 192.168.0.0 255.255.248.0 Serial0/0/0

📝 10. CCNA 200-301 Official Quiz & Knowledge Check

1. When you configure an IP address on a router interface and enable it with `no shutdown`, what routes are automatically added to the routing table?
A. A Connected route (C) to the subnet and a Local route (L /32) to the interface IP (Correct)
B. A Connected route only
C. A Static route and a Default route
D. An OSPF dynamic route
Explanation: Cisco IOS automatically injects a Connected route (C) covering the subnet network address, and a Local route (L /32) covering the router's exact interface address.
2. Examine R1's routing table containing `L 192.168.3.25/32`. What will R1 do when it receives a packet destined for 192.168.3.25?
A. Flood the packet out of all interfaces
B. Receive and process the packet for itself (Correct)
C. Forward the packet to the next-hop router
D. Drop the packet immediately
Explanation: A Local (/32) route indicates that the IP address belongs to the router itself; therefore, R1 consumes the packet internally.
3. What is the fundamental difference between switches and routers when handling unknown destination traffic?
A. Switches flood unknown unicast frames, whereas routers drop unmatched packets (Correct)
B. Routers flood packets, whereas switches drop frames
C. Both devices flood unknown destinations
D. Both devices drop unknown destinations
Explanation: Switches flood unknown unicasts to find destination MACs, but routers never flood — they drop packets that have no matching route.
4. Which command correctly configures a static default route in Cisco IOS?
A. ip route 0.0.0.0/0 10.1.1.254
B. ip route 0.0.0.0 0.0.0.0 10.1.1.254 (Correct)
C. default-route 0.0.0.0 10.1.1.254
D. ip default-gateway 10.1.1.254
Explanation: In Cisco IOS global config mode, static routes require full dotted-decimal netmask notation (ip route 0.0.0.0 0.0.0.0 <next-hop>). Slash notation (/0) is invalid syntax.
5. In a 4-router WAN where R3 is directly connected to 2 subnets, how many additional static routes must be configured on R3 to know all 6 networks in the enterprise topology?
A. 2 routes
B. 4 routes (Correct)
C. 6 routes
D. 1 route
Explanation: With 6 total subnets and 2 already known as directly connected (C), R3 requires exactly 4 static routes to reach all remote networks.
