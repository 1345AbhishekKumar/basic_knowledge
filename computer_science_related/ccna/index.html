⚡ Cisco CCNA 200-301 Golden Rules Cheat Sheet

Core architectural rules and behavioral properties every network engineer must remember:

📡 Collision vs Broadcast

Hub: 1 Collision Domain, 1 Broadcast Domain.
Switch: 1 Collision Domain per port, 1 Broadcast Domain per VLAN.
Router: 1 Collision Domain per port, 1 Broadcast Domain per port.

📦 Frame vs Packet

Frame (L2): MAC addresses change hop-by-hop.
Packet (L3): Source and Destination IP addresses stay constant across end-to-end hops.

🎯 Longest Prefix Match

When multiple routes match a destination IP, the router ALWAYS selects the most specific route (longest prefix length, e.g., /32 beats /24, /24 beats /16, /16 beats /0).

🔒 Password Security

enable secret uses MD5 hash (Type 5) and always supersedes enable password (Type 7 reversible cipher). Always prefer secret.
